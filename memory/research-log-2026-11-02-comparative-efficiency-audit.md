## Three new confirmed P2 defects remain open

The transport verifier can accept its input receipt as report `OutputPath`, overwrite it and return `complete=true`; a subsequent check then fails. Validated local-adapter usage above reservation is discarded into quoted accounting: eight fake calls each report 1,000,000 input tokens, while only 36,365 estimated input tokens are charged and no violation stops later dispatch. This is the opt-in legacy/local-model path, excluded by strong schema-2 offline `run`. An explicitly granted unused raw node can claim 2022 public availability from a retained 2024 receipt at a 2023 origin; current 0.5.0 whole-inventory verification accepts, while the same node as a used ancestor rejects. No contaminated scientific claim, real model spending or production source destruction was shown.

Independent paired fictional controls confirm all three. They are engineering witnesses, not independent scientific observations. Fix directions are exclusive input-disjoint report publication; propagation/reconciliation of validated reported usage with a stop on violation; and receipt-derived availability checks for every supplied raw node. Preserve frozen versions and add new regressions in a separately qualified correction. No closed model retry is authorized.

## Efficiency and evidence proposals

Five pre-dispatch raw hash passes were measured in current policy preparation, but distinct boundaries mean not all can simply be removed. A frozen compiler fixture with 32 selected records/128 fields reads the same 1,052,280-byte JSON file 32 times and fingerprints its frozen task 131 times. Hoisting immutable fingerprints is the clearest redundant computation; one bounded parse per source within existing stable locks is the next candidate. Cross-operation mtime-only digest reuse is not equivalent to content verification. No optimized implementation or speedup was tested. Frozen renderer/packager copies are intentional; no dead shim was proved removable.

Post hoc existing-table analyses show five complete native units, six with one null and one with two nulls: 40/48 populated measurement slots. Eight of ten designed invalid controls pass schema; G2's incremental contribution is identifiable on two fixtures, while other removed guards change jointly. Verification consumes 197.812/203.828 seconds; eliminating generation plus scoring entirely yields only 1.001302 times ideal overall speedup. Logical hashing is 49.002 source-frame equivalents, not physical I/O. Near-zero scoring times limit micro-latency ratios. The attempted universal-threshold criticism was rejected: a valid 3/4 partial report passes 60%, and native 80/100 equivalence holds only for one group with two to four answerable components; multigroup 7/8 separates them.

Immediate enrichment: admission/exactness/coverage matrix, missingness denominators and honest cost diagram. The strongest future study compares TETHER with an independently written simple validator enforcing the same temporal/hypothesis/lineage policy; a minimal hash/schema baseline is diagnostic ablation only. Freeze independent fault specifications and valid near misses, use matched inputs/budgets, and compare admission, replay, accounting/recovery, false admission/rejection and resources/complexity. Already exposed bugs become regressions, never unseen tests. No model or expert is required. Genetics enrichment remains conditional on exact study/cohort/variant/build/allele/effect metadata and a defined estimand; no speculative acquisition.
