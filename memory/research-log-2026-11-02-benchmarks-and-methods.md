## Recommended benchmark portfolio

No inspected external benchmark jointly tests information-availability cutoffs, hypothesis scope and transitive lineage. First propose an independently specified conformance suite and simple independent full-policy comparator, with fixed candidate outputs, valid near misses and hash/schema-only diagnostic ablation. Reject-all is a useful sanity baseline, never successful task utility. Existing exposed audit defects remain regressions rather than unseen test cases.

SciFact is the best first semantic extension, with official evidence/rationale/label scoring and public development labels. Its scorer needs a genuine support/refutation component; current literal extraction does not supply one. LAB-Bench LitQA2 or DbQA is the first recommended biomedical answering task after retrieval/answer support exists. ALCE adds citation-versus-answer quality with fixed passages, but its learned NLI evaluator is not deterministic truth. GenomeArena, RAGPPI gold and CRAG are conditional alternatives. R2E ranking, BixBench computation and AgentDojo action security require capabilities absent from the qualified current route. Replay of fixed candidate answers is harness evaluation, not native answer-generation performance.

Public availability has limits: LAB-Bench releases around80%; current card199LitQA2/520DbQA. GenomeArena720questions but exact source rights/versions need qualification. RAGPPI card500gold+3,720silver=4,220 differs from abstract4,420; separate LLM atomic facts are not independent gold. BiomniBench-DA gated50/100tasks,82.9GB and model judge; TxBench public seven examples only. TRQA has heterogeneous CSV schemas/current viewer cast error. No full acquisition, native scorer operation or expanded storage was qualified. Repository code licenses do not automatically cover embedded datasets/text/weights.

## Real method gaps and existing strengths

All-scheduled accounting, same-output policy projections, declared study/cohort grouping, conflict exclusion, stable reads, basic caches and journals already exist. Do not call them absent. Current entailment utility checks supplied labels/quoted bytes, not semantic truth. Separate source-projection auditor is not a full-policy independent implementation. Study/cohort grouping lacks qualified real identities; clinical evaluator metrics are conditional on resolved nonabstained predictions with explicit exclusions, and current inference is descriptive-only.

Useful transfers: CheckList-style independent behavioral/metamorphic matrices; ALCE/ARES-style separated semantic/source/answer dimensions; AgentDojo-style utility versus forbidden behavior; Inspect-style distinct output/scorer failure outcomes; R2E evidence-set interventions only after a useful ranker; Nextflow-inspired pure completed-step reuse without weakening content/stability guarantees; tau pass^k only for new prospective stochastic trials; CaMeL/AgentSpec-style capabilities/events only if dynamic tools are introduced. An Inspect integration is a proposed alternative to more standalone infrastructure, not a verified equivalent implementation. More agents/debate/memory are not justified for the current copying endpoint.
