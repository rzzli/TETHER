# Bounded interpretation implementation

A repository-only sidecar now constructs immutable source-bound T6 requests from
existing snapshot admission and accepts structured contextual interpretations with
exact decoded UTF8 source quotes. Source reports stay verbatim; inferred prose
and limitations are separate. Evaluator ancestors are denied before dispatch,
prediction features are hidden and outputs cannot populate scorer features or a
clinical probability. Existing Backend.quote/select and default runtime unchanged.

One-use offline replay archives exact response inputs. Durable journals retain
quote/reservation, measured or conservative usage, raw responses and failures;
there is no automatic retry. Verification reconstructs current source admission
and reconciles configuration, quote decisions, code identities and accounting.
Schema checks do not prove entailment, context sufficiency, scientific truth or
free-prose clinical safety. Trusted adapters require transport timeouts; this is
not OS isolation or a live interpretation model adapter.

The original red test and later semantic probes were retained. Independent peer
review exposed negative measured usage and unrelated/missing code proofs passing
verification; both were reproduced and fixed. Full1083 tests/probes/package pass
with unchanged Python-code guard;120 isolated audit tests and28 standard-library
only tests pass. Actual IL6R source admission/replay covers9observations and keeps
65missing inputs/absence false. That scripted quotation is not generated scientific
interpretation or a quality evaluation. Old protected labels were hashed only and
remain unchanged; no native model call/paid provider/scorer mutation occurred.
