# Research log template

- Date and active research objective.
- User constraints and preferred seed papers/systems.
- Sources, backward citation relationships and supplementary searches.
- New findings compared with existing work; distinguish observation, author claim and inference.
- Methods and artifacts created, with exact identifiers/versions where applicable.
- Access failures, checks not run and unresolved uncertainties.
- Proposed next steps and any decisions actually authorized by the user.
- Update [[project-goals]] and the memory index.
