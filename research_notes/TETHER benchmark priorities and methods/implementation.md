# TETHER implementation gaps and benchmark implications

## 1. Which peer methods are implemented, partial, missing or unqualified?

### Takeaway

The main additions should be task-capable semantic answering, better evidence retrieval and evaluated selective answering. Rebuilding provenance, dependence grouping, caches or complete accounting would duplicate existing mechanisms. This November 5 inspection covers 85 maintained Python files in `src/asof` and `packages/tether/src/tether` (the facade is not under `src/tether`), plus selected utilities and current evidence records. [Scope and hashes](<D:/Projects/drug_target_agents/research_notes/TETHER benchmark priorities and methods/implementation-scope.json>).

## 3. What is feasible next without duplicating work?

### Takeaway

BG02 is now closed at commit `4dbe7be`; preserve BG03 → BG04 → BG05. Use a separate native study contract rather than inventing target IDs to fit T1/T6. [Execution plan](<D:/Projects/drug_target_agents/planning/TETHER Benchmark Execution Plan 2026-11-02.md>), [verifier seam](D:/Projects/drug_target_agents/src/asof/study/session.py:87).

### Cited Findings

- SciFact requires claim/document IDs, support/contradiction labels and sentence rationales. Its abstract rationale cap is actually `max(3, shortest gold rationale length)`; sentence scoring considers all predictions. The prose's blanket three-sentence wording is incomplete. Pin the scorer commit/bytes and test native behavior rather than copying prose or illustrative label spelling. [Official implementation, lines 139–145 and 160–170](https://github.com/allenai/scifact-evaluator/blob/master/evaluator/eval.py#L139-L170).
- Local listing found three Qwen2.5-14B GGUF shards. They were not loaded or rehashed. The checked 0.5.2 development environment contains none of scikit-learn, NumPy, SciPy, Torch, Transformers or Inspect; that is not a machine-wide inventory. [Resource listing](<D:/Projects/drug_target_agents/research_notes/TETHER benchmark priorities and methods/implementation-scope.json>).
- Hardware reports 28 logical CPUs, approximately 31.84 GiB physical RAM and an RTX 5070 Ti with 16,303 MiB VRAM. The project `.venv` also lacks those scientific packages; bundled Python has NumPy 2.3.5 but none of the other listed packages. CIM access failed, so memory came from the Windows API and GPU information from `nvidia-smi`. This inventory does not establish model throughput or peak-memory feasibility. [Read-only inventory](<D:/Projects/drug_target_agents/research_notes/TETHER benchmark priorities and methods/bg03-resource-inventory.json>).

### Inferences

Qualify a cheap trainable retrieval/label baseline and native scorer before considering a larger model. Add calibrated rejection and semantic checking as measured ablations, retaining public-reference isolation and failures. Existing checkpoint files do not authorize reopening closed historical model cells. [Plan](<D:/Projects/drug_target_agents/planning/TETHER Benchmark Execution Plan 2026-11-02.md>).

No local SciFact release, new dependency environment or positive native answering run was qualified here. No dataset/model acquisition, provider call, expert recruitment, runtime edit or BG03 execution occurred.
