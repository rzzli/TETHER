# General benchmarks and transferable methods for TETHER

Research checkpoint: 5 November 2026, after the corrected BG02 runs. These notes supersede the earlier survey's **unscored BG02 / version 0.5.1** statements: patched TETHER 0.5.2 / AsOf 0.3.13 and the independent validator each conform on all 109 exposed authored cases; original TETHER fails EP075. The patched run's median measured import-plus-operation time is 0.4290 seconds for TETHER and 0.2608 for the independent implementation, across 327 repeated cells per arm. This finite, instrumented Windows-host result establishes neither a speed advantage nor scientific answering ability. [Causal review](D:/Projects/drug_target_agents/planning/review-assets/tether-equal-policy-v2-20261105/postresult/CAUSAL-REVIEW-20261105.md); [independent reconstruction](D:/Projects/drug_target_agents/data/benchmark/tether-equal-policy-v2-patched-20261105-attempt01/INDEPENDENT-RECONSTRUCTION.json).

This assignment refreshed primary papers, official code and documentation. It ran no benchmark, downloaded no dataset or checkpoint, called no model, changed no runtime, and read no protected expert returns or clinical outcomes. Mutable web branches below are research citations, not pinned execution dependencies. The proposed designs are judgments, not measured gains.

## 1. Which external benchmarks and comparators can establish useful performance now?

### Takeaway

**SciFact is the best next native semantic task; MultiVerS is a concrete solver candidate, not another harness.** Inspect is the relevant framework comparator. ALCE is a valuable subsequent cited-generation test. AgentDojo and the tau family should remain conditional on actual interactive tool capabilities. This recommendation follows the existing SciFact → one LAB-Bench family → Inspect sequence and adds ALCE afterward. [Execution plan](<D:/Projects/drug_target_agents/planning/TETHER Benchmark Execution Plan 2026-11-02.md>); [SciFact](https://github.com/allenai/scifact); [MultiVerS](https://github.com/dwadden/multivers); [Inspect](https://inspect.aisi.org.uk/agent-bridge.html).

### Cited Findings

| Priority | Native task and metrics | Required inputs/solver; feasibility | What the result can establish |
|---|---|---|---|
| **Next: SciFact** | Retrieve scientific abstracts; predict SUPPORT/CONTRADICT and rationale sentence IDs. Official scorer produces abstract-label-only, abstract-rationalized, sentence-selection and sentence-label precision/recall/F1. | Claims, immutable sentence-indexed corpus, split, exact official scorer, real answer producer. Public train/dev have labels; test labels are private. The documented test submission service was not tested here. | Retrieval plus scientific claim/evidence interpretation relative to existing annotations. It does not establish target efficacy or independent clinical truth. [Scorer](https://raw.githubusercontent.com/allenai/scifact-evaluator/master/evaluator/eval.py); [release](https://raw.githubusercontent.com/allenai/scifact/master/README.md). |
| **SciFact solver candidate: MultiVerS** | Joint document label and rationale prediction from shared full-abstract context; published checkpoints include SciFact and out-of-domain `fever_sci`. | Released checkpoint, Longformer scientific base, legacy dependency environment and qualified CUDA execution. `predict.py` explicitly sends the model to `cuda:{device}`; CPU feasibility is not established. Checkpoint fit on local hardware and training-split exposure still need verification. | Supplies actual interpretation, where TETHER currently chiefly selects/seals evidence. Report it as the solver in all matched arms. [Paper](https://aclanthology.org/2022.findings-naacl.6/); [checkpoints](https://raw.githubusercontent.com/dwadden/multivers/main/README.md); [inference](https://raw.githubusercontent.com/dwadden/multivers/main/multivers/predict.py). |
| **Framework stage: Inspect + equivalent policy** | Same admission, artifact verification and recovery obligations, plus native task correctness and complete failure accounting when connected to a solver. Inspect is not a benchmark dataset. | Pinned package, custom task/scorer, transplanted domain policy, recorded added implementation surface, same sources/model/tool permissions/budgets. | Tests integration/portability and cost of equivalent guarantees. Bare Inspect without the domain policy is a weaker-policy diagnostic. Its bridge already checks proposed tool arguments and permits one execution per proposal; dispatch governance is not uniquely TETHER. [Bridge contract](https://inspect.aisi.org.uk/agent-bridge.html). |
| **After task answering: ALCE** | ASQA/QAMPARI/ELI5 generated answers with citations. Report native answer correctness, citation precision/recall and fluency, rather than a single “grounded” score. | Answer-capable generator, passage IDs/text, reference answers, pinned learned attribution evaluator. Released top-100 retrieval results permit an initial fixed-passage experiment. Rebuilding complete retrieval indices is a separate large resource commitment. | Whether attributed statements are supported while retaining useful answers. Not a historical-lineage or biomedical-validity benchmark. [Paper](https://aclanthology.org/2023.emnlp-main.398/); [release](https://raw.githubusercontent.com/princeton-nlp/ALCE/main/README.md). |
| **Conditional: CRAG** | Factual QA with mock search/knowledge APIs; native auto-evaluation scores correct +1, missing 0, incorrect −1. | QA agent, supplied results/API environment, qualified matcher/judge and licensed assets. | Useful error-versus-coverage stress test. Dynamic/query-time metadata does not supply complete source-annotation chronology; a historical test would be a separately declared derivative. [Official release](https://raw.githubusercontent.com/facebookresearch/CRAG/main/README.md). |
| **Later: AgentDojo** | Untrusted tool-return injection; benign task completion, utility under attack and attacker success must remain separate. | Agent capable of the environment's actual tool tasks, pinned attack/defense configuration, sandbox and benign counterpart runs. | Security versus retained utility. An inert verifier or reject-all system cannot demonstrate useful agent security. [Primary paper](https://arxiv.org/abs/2406.13352). |
| **Later: tau-bench family** | Simulated user/API interaction; compare terminal database state to goals and all-success reliability across repeated trials (`pass^k`). | Conversational tool agent, simulator model, domain state/policy and exact versioned environment. | Repeated policy-following reliability, not source entailment. Borrow its reliability design now; do not claim native tau performance from archived transcript checks. The cited source is the original 2024 benchmark, not an assertion about current successor releases. [Primary paper](https://arxiv.org/abs/2406.12045). |

SciFact details that should change the implementation plan:

- **Use the official scorer's implementation, not a verbal approximation.** Its abstract-rationale limit is `max(3, shortest_gold_rationale_length)`, while the older guide says first three sentences. Sentence scoring requires the selected sentence's complete gold rationale set; it is not ordinary independent sentence-label accuracy. Preserve native IDs/order and explicit empty predictions. [Official scorer](https://raw.githubusercontent.com/allenai/scifact-evaluator/master/evaluator/eval.py).
- **Do not treat “not enough information” as a failed operation.** MultiVerS removes NEI document predictions from the evidence dictionary while preserving claim IDs, including claims with no retrieved documents. A correct empty-evidence task prediction, harness policy abstention, missing response and timeout need distinct statuses. [Output formatting](https://raw.githubusercontent.com/dwadden/multivers/main/multivers/predict.py).
- **Separate accessible corpus from answer keys.** The claim schema includes `evidence` and `cited_doc_ids`; the latter contains source-citation metadata useful for an explicitly supplied-document condition, but should not silently become open-retrieval input. Retain train/dev/test and model-fitting provenance. [Schema](https://raw.githubusercontent.com/allenai/scifact/master/doc/data.md); [open versus oracle modes](https://raw.githubusercontent.com/allenai/scifact/master/README.md).
- **Terms differ by product:** claims/evidence annotations CC BY 4.0, abstract corpus ODC-By 1.0, repository code Apache 2.0. Check checkpoint and downstream model terms separately. [License](https://raw.githubusercontent.com/allenai/scifact/master/LICENSE.md).

ALCE implementation details also matter: its evaluator exposes ASQA string exact-match coverage, QAMPARI answer-list precision/recall/F1, ELI5 claim-NLI coverage and citation precision/recall. The released code uses `google/t5_xxl_true_nli_mixture` for attribution, truncates answers at the first newline, and defaults to at most three cited passages for citation evaluation. Preserve raw outputs before that native transform; report a changed evaluator as a derivative. [Evaluator](https://raw.githubusercontent.com/princeton-nlp/ALCE/main/eval.py).

### Inferences

- External native labels create a scientific interpretation target that byte hashes and copying cannot solve. However, **a provenance-only gate has no automatic mechanism to improve semantic accuracy**. First measure native errors; evaluate any new semantic gate as an added component with its own ablation and cost. [Current interface limits](D:/Projects/drug_target_agents/src/asof/study/diagnostic_codec.py); [SciFact scoring](https://raw.githubusercontent.com/allenai/scifact-evaluator/master/evaluator/eval.py).
- A published MultiVerS baseline is likely a lower implementation-risk first solver than inventing a general planner. That is a feasibility judgment, not a claim that its old dependency stack already runs locally. Audit `scifact` checkpoint training/tuning exposure; `fever_sci` provides a different adaptation condition, not proof of zero contamination. [Training instructions](https://raw.githubusercontent.com/dwadden/multivers/main/doc/training.md).
- Broad assistant exams and interactive agent suites are poor primary endpoints until a corresponding solver exists. Better scores on unrelated tool tasks would not directly answer whether TETHER preserves useful scientific evidence interpretation. [AgentDojo task definition](https://arxiv.org/abs/2406.13352); [tau task definition](https://arxiv.org/abs/2406.12045).

### Gaps

- Exact model/checkpoint hashes, complete training exposure, GPU capacity, package installation compatibility and native scorer agreement are unverified. No test-server accessibility or leaderboard submission was established. Public release documentation is not local acquisition evidence. [MultiVerS setup](https://raw.githubusercontent.com/dwadden/multivers/main/README.md); [SciFact release](https://raw.githubusercontent.com/allenai/scifact/master/README.md).
- **Concrete acquisition routes, not completed pins:** the official README links `https://scifact.s3-us-west-2.amazonaws.com/release/latest/data.tar.gz`; `latest` is mutable. This research did not fetch the archive or establish its version/checksum. The official scorer source is `https://raw.githubusercontent.com/allenai/scifact-evaluator/master/evaluator/eval.py`; its exact commit and byte hash must likewise be captured before implementation. Preserve [official product licenses](https://raw.githubusercontent.com/allenai/scifact/master/LICENSE.md) alongside the archive manifest. Do not fabricate a historical release ID from a retrieval date. [Official release link](https://raw.githubusercontent.com/allenai/scifact/master/README.md); [scorer route](https://raw.githubusercontent.com/allenai/scifact-evaluator/master/evaluator/eval.py).
- The cited benchmarks do not establish all TETHER chronology/authorized-use/ancestor obligations on naturally occurring records. Preserve native task scoring and add separately labeled policy perturbations; do not invent historical dates to make a new benchmark appear to test historical eligibility. [TETHER contract](D:/Projects/drug_target_agents/planning/review-assets/tether-equal-policy-20261102/POLICY-SPEC.md).

## 2. Which peer methods would improve the project, rather than rename existing features?

### Takeaway

Prioritize evaluated semantic support, context-sensitive retrieval, evidence-use interventions and selective prediction. TETHER already has immutable evidence, ancestry checks, hypothesis scope, declared study/cohort dependence grouping, budgets and complete-result accounting. The additions below strengthen what is measured and how evidence is interpreted; they do not claim those existing capabilities are missing. [Local capability audit](<D:/Projects/drug_target_agents/research_notes/TETHER benchmark fit and advances/current_project_gap_map.md>); [corrected BG02 findings](D:/Projects/drug_target_agents/planning/review-assets/tether-equal-policy-v2-20261105/postresult/CAUSAL-REVIEW-20261105.md).

### Cited Findings

| Rank | Transferable method and source | Concrete addition and required qualification |
|---|---|---|
| **1** | **Full-context joint claim/rationale interpretation — MultiVerS.** Extracted fragments can lose scope/coreference; its shared encoding labels the document and selects rationales together. [Paper](https://aclanthology.org/2022.findings-naacl.6/). | Preserve whole abstract and sentence offsets in the task adapter. Compare full abstract with extracted-only text at the same documented budget. Qualify support, contradiction and NEI, rather than checking only exact quotation. |
| **2** | **Separate retrieval, answer and attribution evaluation — ALCE / ARES.** ARES distinguishes context relevance, answer faithfulness and answer relevance; its original error correction uses labeled observations. [ARES](https://aclanthology.org/2024.naacl-long.20/); [ALCE](https://aclanthology.org/2023.emnlp-main.398/). | Add per-component errors and a separately qualified judge. Existing public reference labels can supply appropriate task validation; AI consensus does not replace an independent labeled correction set. Keep semantic disagreements rather than converting them into authoritative truth. |
| **3** | **Rationale-use interventions — ERASER.** Its metrics compare the original predicted-class score with scores after removing rationale or retaining rationale alone; annotation overlap and influence are distinct. [Paper](https://aclanthology.org/2020.acl-main.408/); [metrics](https://raw.githubusercontent.com/jayded/eraserbenchmark/master/rationale_benchmark/metrics.py). | On a score-producing SciFact model, measure rationale sufficiency/comprehensiveness and no-evidence/placebo controls. If probabilities are unavailable, report native prediction/accuracy changes as a new intervention metric, not the ERASER score. Removing context can itself change the task. |
| **4** | **Selective answering — selective classification and conformal risk control.** Reject-option methods trade coverage for error. CRC bounds expected bounded monotone loss using exchangeable calibration/test examples. [Selective classification](https://arxiv.org/abs/1705.08500); [CRC](https://arxiv.org/html/2208.02814). | Freeze thresholds on a disjoint calibration split and report risk–coverage curves. Do not infer a guarantee on error *among answered cases* from a theorem about a different unconditional loss. Dependent claims, non-monotone objectives and distribution shift need explicit treatment. |
| **5** | **Source-family dependence and grouped uncertainty.** Inspect supports cluster-aware standard errors/intervals; TETHER already joins declared study/cohort evidence groups. [Inspect metrics](https://inspect.aisi.org.uk/metrics.html); [existing grouping](D:/Projects/drug_target_agents/src/asof/features.py). | Preserve article/study identity, split by justified source families and resample groups. Add duplicate/rephrased-source invariance and leave-source-family-out probes. These are proposed TETHER controls, not a claim that Inspect discovers biological dependence. Unknown study IDs remain unknown dependence. |
| **6** | **Capability × perturbation testing — CheckList.** Minimum functionality, invariance and directional tests complement aggregate held-out accuracy. [Paper](https://aclanthology.org/2020.acl-main.442/). | Add externally labeled semantic boundary controls: negation, population/context qualifiers, contradictory versus irrelevant passages and valid neighbors. Preserve developer exposure; more authored cases do not produce a hidden generalization test. |
| **7** | **Preserved judge failures and repeat reliability — Inspect / tau.** Inspect may exclude scorer errors/unscored outcomes from default accuracy; tau evaluates all-success reliability rather than best-of-k. [Scoring policy](https://inspect.aisi.org.uk/scoring-policy.html); [tau](https://arxiv.org/abs/2406.12045). | Retain all scheduled cases, raw epoch records, judge failures and operational failures; report both native metrics and end-to-end useful completion. Repeated deterministic archive verification is not independent model reliability evidence. |
| **8** | **Benign utility paired with hostile evidence — AgentDojo.** Its threat is untrusted tool text redirecting an agent. [Paper](https://arxiv.org/abs/2406.13352). | Initially add bounded retrieved-text injection controls with benign counterparts. Claim a component test until native interactive tasks, attacker goals and tool effects are actually executed. Source integrity alone does not make retrieved instructions safe. |

Two intellectual links are directly supported by the primary sources: SciFact's official repository identifies MultiVerS as its later scientific-verification model, and MultiVerS uses SciFact's task definition; ALCE's attribution code explicitly adapts the Attributed-QA evaluator. Other methods in this table are **methodological comparisons**, not an asserted citation chain. [SciFact update](https://raw.githubusercontent.com/allenai/scifact/master/README.md); [MultiVerS paper](https://aclanthology.org/2022.findings-naacl.6/); [ALCE code attribution](https://raw.githubusercontent.com/princeton-nlp/ALCE/main/eval.py); [Attributed QA](https://raw.githubusercontent.com/google-research-datasets/Attributed-QA/main/README.md).

### Inferences

- **Measure evidence use, not merely evidence presence.** A case that cites the right abstract but does not change when decisive evidence is removed can have a correct answer for the wrong reason. Combine native accuracy, rationale overlap and controlled input changes; none alone proves internal reasoning or memorization. [ERASER](https://aclanthology.org/2020.acl-main.408/).
- **Improve retrieval only after decomposing the failure.** Compare current lexical selection, BM25 and a qualified reranker at identical document/byte limits; use relevant-abstract recall plus native answer F1. Gold supplied abstracts are an oracle ablation, not an open-retrieval score. Active search is justified only if retrieval remains a measured bottleneck. [SciFact open/oracle distinction](https://raw.githubusercontent.com/allenai/scifact/master/README.md); [current retriever](D:/Projects/drug_target_agents/src/asof/retrieval.py).
- **Evidence duplication and model-confidence calibration are different issues.** Avoiding repeated cohort weights already exists; semantic paraphrase/citation-family detection would need independently checked mappings. Claim counts, citations and stochastic repeats should not multiply the independent evaluation N. [Existing grouping](D:/Projects/drug_target_agents/src/asof/features.py); [cluster metrics](https://inspect.aisi.org.uk/metrics.html).

### Gaps

- No semantic judge, confidence threshold or dependence-discovery model was fitted or validated in this assignment. CRC should stay conditional until its loss and exchangeability assumptions match the proposed task. The cited sources do not establish calibrated clinical success probabilities for TETHER. [CRC assumptions](https://arxiv.org/html/2208.02814); [scorer scope](D:/Projects/drug_target_agents/src/asof/scorer.py).
- A public reference annotation can be reused without recruiting another reviewer, but it does not independently validate an unrestricted new biomedical dossier. Preserve the retired expert-response boundary and distinguish benchmark-reference correctness from biological truth. [Existing interpretation limitation](D:/Projects/drug_target_agents/src/asof/study/diagnostic_codec.py).

## 3. What fair experiment and stage gates would turn these ideas into a stronger paper?

### Takeaway

The next defensible claim is **useful task performance under explicit evidence controls at measured overhead**, not better therapeutic prediction or unique orchestration. BG02 now demonstrates that the same exposed obligations can be independently implemented and that TETHER's first version had a real replay defect; the next experiment must be able to show both benefit and harm to native task answering. [Causal result](D:/Projects/drug_target_agents/planning/review-assets/tether-equal-policy-v2-20261105/postresult/CAUSAL-REVIEW-20261105.md); [resource reconstruction](D:/Projects/drug_target_agents/data/benchmark/tether-equal-policy-v2-patched-20261105-attempt01/INDEPENDENT-RECONSTRUCTION.json).

### Cited Findings

- Inspect already supplies task/scorer extension points and model-proposed tool-execution checks, but its opt-out `require_proposal=False` explicitly removes that particular guarantee. A comparison must pin configuration and disclose any added policy code; a framework name does not specify the enforced contract. [Agent Bridge](https://inspect.aisi.org.uk/agent-bridge.html).
- Default scoring can omit unscored/errored cases. Native accuracy is therefore not automatically correct-and-admitted completion over the scheduled set. Keep raw outcomes and reconstruct the complete denominator alongside official metrics. [Inspect scoring policy](https://inspect.aisi.org.uk/scoring-policy.html).
- Native ALCE retrieval bundles include oracle reranking as well as ordinary retrieval. An oracle passage ordering cannot be silently used in the ordinary retrieval arm. [Official release](https://raw.githubusercontent.com/princeton-nlp/ALCE/main/README.md).

### Inferences

Recommended protocol, preserving the existing stage order:

1. **Qualify one native SciFact producer and scorer.** Seal data, versions, permissions, checkpoint and training exposure; verify native output/scoring on invented fixtures and answer-capable positive controls. Freeze public development IDs before predictions. Keep labels/rationales inaccessible to the solver. If CUDA/legacy dependencies cannot be qualified, retain a documented blocker or separately qualify another solver; do not replace answering with gold replay. [Inference implementation](https://raw.githubusercontent.com/dwadden/multivers/main/multivers/predict.py); [official scorer](https://raw.githubusercontent.com/allenai/scifact-evaluator/master/evaluator/eval.py).
2. **First isolate admission on fixed candidates.** Produce each native candidate once, then give identical candidate/source artifacts to ungated reporting, the independent equal-policy validator, and TETHER; add Inspect with the same policy in its planned stage. This identifies effects of admission without adding extra model reasoning. Keep raw native output, parser result, policy outcome and evaluator result separate. [Existing equal-policy protocol](D:/Projects/drug_target_agents/planning/review-assets/tether-equal-policy-v2-20261105/CORRECTED-PROTOCOL.md).
3. **Then test end-to-end behavior, if the gate can cause revision or new retrieval.** Hold solver, evidence access, allowed calls, token limits and total compute budget fixed across arms. Give all arms the same revision opportunities. Otherwise a gain may reflect extra generation/judging rather than the framework. If semantic checking is new, factorially separate provenance-only versus provenance-plus-qualified-entailment; do not attribute a new learned model's gain to byte verification. [ALCE's separated answer/citation targets](https://aclanthology.org/2023.emnlp-main.398/); [current semantic scope](D:/Projects/drug_target_agents/src/asof/study/diagnostic_codec.py).
4. **Report a paired utility/constraint panel.** Native F1/accuracy; correct-and-admitted/scheduled; task-correct empty evidence where applicable; semantic wrong-but-admitted; policy-ineligible admitted; correct-but-rejected; policy abstention; model/parser/tool/judge failures; and full scheduled count. Report conditional error among admitted outputs only with coverage. Fix the meaning of “unsafe” to the tested policy/reference; wrong-but-provenance-valid is a distinct category. [SciFact output semantics](https://raw.githubusercontent.com/dwadden/multivers/main/multivers/predict.py); [Inspect denominator behavior](https://inspect.aisi.org.uk/scoring-policy.html).
5. **Calibrate separately and evaluate evidence interventions.** Split by source/claim family before threshold tuning; add no-evidence, irrelevant-evidence, decisive-rationale removal and full-context conditions. Use matched coverage for selective-risk comparisons and retain confidence/judge uncertainty. Public development scores remain development scores; model pretraining exposure is not established by the benchmark release date. [ERASER](https://aclanthology.org/2020.acl-main.408/); [selective classification](https://arxiv.org/abs/1705.08500).
6. **Continue one source-feasible LAB-Bench family, then Inspect, then optional ALCE.** Do not expand to every benchmark simultaneously. Inspect's value is equal-policy composition and cost, not a guarantee of improvement; ALCE adds long-form attribution only after a useful native answer route exists. [Existing plan](<D:/Projects/drug_target_agents/planning/TETHER Benchmark Execution Plan 2026-11-02.md>); [ALCE task](https://aclanthology.org/2023.emnlp-main.398/).
7. **Retain total cost and negative findings.** Include model, retriever and judge usage, parsing/source verification, imports and preparation, failed calls, wall time and peak memory. Report startup and steady-state experiments separately if both exist. The current 0.4290-versus-0.2608-second import-plus-operation observation is a reason to measure overhead honestly, not to remove guarantees or hide the comparator. [Measured resource record](D:/Projects/drug_target_agents/data/benchmark/tether-equal-policy-v2-patched-20261105-attempt01/INDEPENDENT-RECONSTRUCTION.json).

These are prospective stages, not execution authorization or completed benchmark results. The scientific prerequisite is an answer-capable native solver with isolated references and suitable metrics; another external expert response is not required for scoring existing public annotated tasks. [SciFact labels/release](https://raw.githubusercontent.com/allenai/scifact/master/README.md).

### Gaps

- Exact effect sizes, power and improvement thresholds cannot be inferred from BG02's 109 deliberately authored controls. Use the actual external task count, dependence structure and paired error rates when planning sensitivity; do not reuse synthetic conformance proportions as expected semantic accuracy. [BG02 scope](D:/Projects/drug_target_agents/planning/review-assets/tether-equal-policy-v2-20261105/CORRECTED-PROTOCOL.md).
- This survey has not qualified any external package, solved a benchmark, established a protected held-out set or estimated local GPU peak memory. Such evidence belongs in the next implementation gate, with separate data/model/scorer manifests. [MultiVerS setup requirements](https://raw.githubusercontent.com/dwadden/multivers/main/README.md).
