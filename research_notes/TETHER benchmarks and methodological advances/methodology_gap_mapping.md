# TETHER methodological capability and gap map

## What is implemented, partial, absent or not yet evaluated?

### Takeaway

TETHER already implements several good evaluation controls that should not be sold as new proposals: fixed all-output accounting, paired policy projections over the same outputs, exact source replay, explicit missingness, declared dependency grouping and separation of evaluation inputs. Its largest methodological gaps are an independently implemented policy-equivalent comparator, scientific entailment verification, qualified source dependence, external benchmark adapters, and evaluation beyond exposed technical fixtures. The current schema-2 path is offline extraction; the legacy model/interpretation paths are separate, closed development branches. - The shortest credible next scientific argument is an **incremental assurance** result: same proposed claims and same evidence, with independently scored correctness and separately measured eligibility errors, false rejections, coverage and total cost. - A peer's architectural feature can already be partially present under another name. ## Which peer methods transfer usefully, and which do not?

### Takeaway

Prioritize independent matched verification and systematic valid/invalid contrasts, then safe computation reuse. Scientific evidence attribution, calibrated abstention and secure tool-action policies are defensible later extensions only when their missing prerequisites exist. Their peer-reported benefits do not transfer automatically to this offline reporting task. [Prior audit](<D:/Projects/drug_target_agents/reports/TETHER efficiency and comparative value.md>); [current offline scope](<D:/Projects/drug_target_agents/docs/TETHER-CATALOG-POLICY.md:39>)

### Cited Findings

- **R2E: evidence-conditioned scoring and perturbation attribution.** Its answer identity is masked, and the model represents each candidate through retrieved evidence; Shapley-style analysis attributes score differences to evidence. New evidence can be incorporated without retraining. This differs from TETHER's source membership/exactness and coefficient contributions. The transferable idea is evidence deletion/addition and rank sensitivity, provided a meaningful validated score exists. Shapley attribution is attribution of the model's score, not a biological causal effect. [ACL primary paper record](https://aclanthology.org/2025.acl-long.167/)
- **CaMeL: explicit control/data-flow separation and per-value capabilities.** The trusted request drives a program; untrusted extraction is quarantined, and an interpreter checks fine-grained policies on tool data flows. Its paper explicitly excludes some text-to-text false-summary attacks, assumes trusted user input/uncompromised memory, describes side channels and reports utility/cost tradeoffs. Therefore it cannot be imported as an entailment guarantee or a replacement for TETHER's source correctness checks. Transfer only if TETHER later permits dynamic tools or side effects, with explicit scientific source roles and destination policies. [Primary v1, Sections 3–6](https://arxiv.org/html/2503.18813v1)
- **AgentDojo: measure utility as well as security under adversarial inputs.** Its threat involves untrusted tool results redirecting an agent. A future TETHER derivative can pair malicious source instructions with benign task-equivalent controls, but this is an adapted task if its tools/endpoints differ. A no-tool extractive system cannot claim general agent-security superiority on tasks it cannot perform. [Primary paper](https://arxiv.org/abs/2406.13352)
- **tau-bench: repeated-run reliability and environment-state checks.** The original paper evaluates final database state against goal state and introduces pass^k for success across repeated trials. That is a useful evaluation principle for future stochastic specialists; the current deterministic reporting study should instead retain exact reproducibility and fault-injection results. [Primary paper](https://arxiv.org/abs/2406.12045)
- **Nextflow: dependency-aware completed-task reuse.** Task cache identity incorporates script, environment/container and inputs; reusing a task also requires its outputs and valid exit state. Its default file keys use metadata; `deep` uses content, and `lenient` uses less metadata. TETHER should borrow explicit identity and completed-step reuse, not weaken content assurance to the default metadata key. A content hash still needs a stability interval when files can mutate. Reuse only proven pure completed steps, and keep uncertain external calls nonretriable. [Task cache and resume](https://docs.seqera.io/nextflow/cache-and-resume); [file modes](https://docs.seqera.io/nextflow/reference/process/directives/cache)

### Inferences

- Adding more agent roles, debate rounds or self-criticism has no demonstrated necessity for the current exact-report endpoint. The literal baseline already solves it; such additions must earn their added cost on a separate task requiring interpretation or decision-making. [Native baseline result and ceiling](<D:/Projects/drug_target_agents/paper/revisions/20261102/manuscript.md:77>)
- A transportable benchmark improvement is often an **evaluation design**, not a model architecture: fixed pairs, independent known labels, useful-answer retention, benign/adversarial distinction, complete accounting and controlled budgets. TETHER already has parts of this design and should extend them instead of claiming all are absent. [Study design](<D:/Projects/drug_target_agents/paper/revisions/20261102/manuscript.md:79>)
- Public benchmark labels can provide existing third-party annotations without reinstating external expert recruitment. They still need rights/version/split/exposure review, and adaptation changes what can be compared to published scores. [Current explicit permission boundary](<D:/Projects/drug_target_agents/TODO.md>)

## What evaluation should be proposed next?

### Takeaway

Use two separately labeled tracks: **assurance performance on source-bound proposed outputs**, which can start with deterministic and recorded artifacts, and **scientific answer quality**, which needs an appropriate supported task and a semantic/decision component. Reporting a popular biomedical benchmark score without this separation would conflate generator knowledge with harness guarantees. [Current guarantees](<D:/Projects/drug_target_agents/docs/TETHER-VERIFICATION-SCOPE.md>); [paper endpoint](<D:/Projects/drug_target_agents/paper/revisions/20261102/manuscript.md:9>)

### Cited Findings

1. **First repair CE01–CE03 before performance comparison.** They affect receipt retention, known usage accounting and inventory temporal consistency. Preserve a frozen baseline and qualify a new version. The audit's now-exposed witnesses are valuable regressions but cannot serve as independent unseen evidence. [Open corrections](<D:/Projects/drug_target_agents/TODO.md>)
2. **Freeze the estimand and matched inputs.** Primary assurance metrics: false admission among known-invalid proposals, false rejection among known-valid proposals, unconditional correct useful answers per scheduled case, retained evidence coverage, source-linked exactness, wall/CPU time, peak memory, logical source bytes, and all failures. A coverage-conditioned error rate is secondary and always paired with coverage. Current exactness and all-cell aggregation are available implementation foundations. [Scorer](<D:/Projects/drug_target_agents/src/asof/study/source_fact_evaluation.py:88>); [aggregate](<D:/Projects/drug_target_agents/src/asof/study/source_fact_evaluation.py:192>)
3. **Use three clearly different comparators.** The same proposal producer under (a) hash/schema diagnostic ablation, (b) independently written simple full-policy validator, (c) TETHER. Hold producer outputs fixed for checker-quality comparisons. A second, separately labeled end-to-end experiment can later include generation and tool use. [Reason for the matched full-policy baseline](<D:/Projects/drug_target_agents/reports/TETHER efficiency and comparative value.md>)
4. **Define actual independent units.** Report performance by task/source/fault family; group multiple transformations of a shared seed instead of treating each as an independent observation. Biological applications additionally need study/cohort identities. The current selected 12 units cannot supply those identities. [Dependence limitation](<D:/Projects/drug_target_agents/paper/revisions/20261102/manuscript.md:63>); [current descriptive-only evaluator](<D:/Projects/drug_target_agents/src/asof/evaluation.py:118>)
5. **Separate benchmark reuse from derivative evaluation.** A public claim-evidence set can supply independent content labels. Temporal/hypothesis/ancestor perturbations added by this project form a TETHER-derived conformance suite, not the original benchmark leaderboard. Under the current API, existing external benchmarks will need explicit adapters and controls; no drop-in claim is supported by this source pass. [Adapter boundary](<D:/Projects/drug_target_agents/src/asof/study/source_fact_adapters.py>)

### Inferences

- A new external evaluation need not require model spending initially: evaluate prepared candidate outputs from public licensed artifacts if available, with verified labels held evaluator-only. However a deterministic source copier cannot supply a genuine SciFact entailment classification or ALCE natural-language answer-quality baseline. Such tasks need an explicit component and should not be described as current capability.
- Failure and cost decomposition can strengthen the paper immediately using existing aggregate artifacts, but is post hoc descriptive evidence. General performance claims need a new protocol and representative task frame. Existing all-output accounting is a positive starting point, not proof of broad reliability.
- A result of equal correctness and greater TETHER cost is an acceptable scientific outcome. It would narrow the contribution to a transparent reference implementation, while failures unique to the lean comparator would identify concrete incremental value. The outcome should be specified before the test suite is exposed to implementation authors.

- Benchmark-specific licensing, exact sizes, evaluator availability and ranking are delegated to the biomedical and general benchmark researchers. This note should be synthesized with those inventories; it does not authorize execution or new acquisition.
