## Source and history boundary

Every stage receives the unchanged complete original request and a table of
original source aliases, observation IDs and quotation pointers. Source equality
is checked rather than inferred from matching names. Only the two packaged
invented requests are executable; the CLI has no real-data or arbitrary-response
input option.

Prior-stage feedback contains source aliases only. It is explicitly untrusted
selection, not scientific evidence. The compiler reloads prior receipts and
responses, checks the comparison/fixture/arm/stage identity before recursive
verification, requires the parent journal's acceptance anchor and verifies the
fixed recorded transport stimulus. An individually valid external cell is not
authorized history. Prior prose, evaluator answers, human references and new
source membership cannot enter through this feedback channel.

The strict flat response validator keeps answered/partial/abstained states,
requires the appropriate `abstention_reason`, validates paired original citations
and rejects malformed content without repairs. Literal source reports must equal
their cited string. Authored caution/inference stays unchanged; materialized exact
quotations appear in separate fields. Mechanical validation does not prove
entailment, underlying biological credibility or clinical transfer.

## One shared budget per fixture

All four arms share one unchanged default case budget:16 calls,32,000 input,
8,000 output,$0 and300 seconds. The retained max_retries field remains1, while
this route performs zero automatic retries. The two fixtures are separate cases.
Pure baselines consume no fabricated model-call or token reservation.

Complete six-stage worst-case reservations fit for the invented fixtures:
31,715 /28,503 input and6,144 output. Proof metadata stays outside the measured
prompt. Every actual payload is remeasured; no source trimming or budget increase
is used to make it fit. The parent deadline also covers preparation and pure work.
Child allocations share its time origin, and the recorded consumption boundary
checks expiry. Replay subtracts elapsed child time when checking later allocations;
nonincreasing numbers alone are insufficient.

Failures preserve parent and cell journals, original responses where captured,
stage dispositions and best-effort failure markers. Later unrun stages remain
explicitly undispatched. The route provides no retry/resume operation.

## Commands and verification

```powershell
python -m tether_engine.study.fixed_evidence_smoke smoke --output data/cache/comparison-example
python -m tether_engine.study.fixed_evidence_smoke verify --path data/cache/comparison-example --sha256 YOUR_RETAINED_SHA256
```

Choose a new directory and retain the reported receipt SHA256 independently.
Verification checks the exact file/directory inventory, current trusted package
and source-only resources, all child receipts, same-run history, shared budgets,
unchanged sources, original authored text, literal quotations and neutral views.
It never imports archived code or repeats generation. Fixed assignment keys remain
outside reviewer files; deterministic labels are not randomized blinding.

The prepared-stage API is `prepare_stage(root, run_id, fixture, arm, stage_index)`;
`prepare_payload(stage)` renders the frozen prompt projection.
`RoleRecordedVerifier` supplies strict source/history/response checks to existing
StudySession/RecordedBackend primitives. No second execution framework or native
adapter was added.
