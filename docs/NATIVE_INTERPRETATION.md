## Caller authority and execution

`authority_four_arm.smoke` retains its recorded default. An explicit trusted
`NativeExecutionConfig` selects the native mode. It binds the approved existing
runtime/model assets, loopback port, one-slot context and fixed launch flags.
This is a Python capability supplied by the operator; a backend ID, archived
absolute pathname or serialized callback name cannot select executable behavior.
There is no native execution CLI in this milestone.

`TokenQuotedNativeBackend` reuses the one-use `LocalBackend` HTTP transport.
Each stage receives an anchored whole-prompt tokenizer quote, original request,
payload fingerprint and earlier parent/caller deadline. Tokenizer weight hashes
must match the model's approved assets. Positive owned-server checks occur before
dispatch; no discovery or process killing by port is performed.

One AsOf stage, five adapted Virtual Biotech stages and both deterministic
baselines share the unchanged budget: 16 calls, 32,000 input/8,000 output tokens,
$0 and 300 seconds. Startup, source preparation, token counting, calls, shutdown
and sealing consume that timer. Source admission and qualification of every
retrieval candidate precede server launch. Ordinary stable-file leases cover the
original source/model inputs. The deadline is checked around synchronous work;
this does not establish hard preemption of arbitrary file or OS operations.

## Assertions, history and accounting

Responses use [original-path quote IDs](INTERPRETATION_INTERFACE.md). The adapter
retains original native bytes, exact echoed settings, complete positive stop and
usage. Authored assertions and materialized exact quotations remain separate.
Accepted history comes from earlier same-arm accepted quote source bindings,
never generated prose. Features stay empty and clinical probabilities stay null.

Known HTTP/model attempts, unknown attempts, measured usage and conservative
reservations have separate fields. A complete retained body can recover reported
usage if transport close fails before returning it; this does not rewrite the
conservative journal reservation. Malformed or rejected content still costs its
reported usage. Root accounting failures preserve the primary error and report
accounting as unavailable. Recovery inspects artifacts without repeating calls.

The explicit `simulated_native_transport` scope is for trusted engineering
fixtures. It forbids the default real process factory, labels process/HTTP counts
as simulated, reports zero actual model calls and stores fixture usage separately
from observed model usage. Trusted callbacks are not an OS sandbox or independent
attestation of execution. Passing simulation does not qualify model outputs.

## Pure replay and relocation

Version 0.3.10 also rejects native durations that reach/exceed a complete typed
cell budget. Controller finalization and replay reconcile wrapper time with the
validated child report using the existing absolute 1 µs rounding tolerance.
This metadata check does not prove hard preemption or actual model feasibility.

```python
verified = verify(
    run_root, receipt_sha256,
    source_roots={"project": project_root, "raw": approved_raw_root},
    native_roots={"model": approved_model_root},
    deadline=absolute_deadline,
)
```

The trusted installed verifier rechecks source lineage, catalog/temporal policy,
all-candidate retrieval, original prompts, history, token quotes, concrete adapter
identity, native wrappers, launch proofs, startup context, clock order, terminal
cleanup, accounting, baselines and final views. It never starts or contacts a
server, runs tokenization or imports code from the archive. Original source/model
roots are explicit caller inputs; archived locations are metadata only.

A copied run bundle can be verified with its original location unavailable while
approved source/model originals remain available. This is run-bundle relocation,
not restoration of the entire original data/model collection or an independent
backup. Each older accepted run retains its matching preserved verifier.

## Qualification boundaries

Retained evidence is under
[the native integration workstream](../planning/review-assets/recovery-step9-native-integration-20261027/CONTRACT.md).
Whole-case fixture tests exercise failure, interruption, concurrent reservation,
source eligibility, partial accounting, shutdown and replay. Acceptance passes
1,737 full tests without failures/errors/skips, 324 unchanged pins, seven installed
legacy families and nine matching old verifiers. Eight installed duration cases
pass. The current real-input simulation takes 295.922 seconds, reserving 24,558
input/6,144 output tokens. Installed source/model replay and guarded run-copy
relocation take 79.734/76.359 seconds; all guard lists are empty. See the
[correction closeout](../planning/review-assets/recovery-step9-native-duration-20261028/CLOSEOUT.md).
Only 4.078 seconds remain in the fixed case budget without actual startup or
inference; real native-case feasibility is unestablished. The timing pair is not
a controlled performance comparison.

The fixed actual-DLL typed JSON round-trip passes. Unchanged-schema conversion
closes **negative**: the pinned converter explicitly warns that unsupported
nonblank patterns accept any string. The returned grammar and diagnostics are
retained in the [disposition](../planning/review-assets/recovery-step9-native-grammar-20261028/DISPOSITION.md).
No native document/EOG corpus, vocabulary, model or server stage followed.
This does not qualify ABI behavior beyond the tested operation or reproducible
source/build equivalence. A separately versioned generation-contract correction
must preserve strict acceptance/post-validation and requalify affected contracts.
Actual CPU/GPU execution feasibility, source/question sufficiency and model
answer quality remain unverified. A future
native experiment needs its own finite prospective declaration after engineering
acceptance and grammar qualification. Pending independent human references, fresh
case qualification and R10–R16 scientific gates remain open.
