# Coordinator-held candidate follow-up

**WITHHOLD this folder until each reviewer has submitted an independent source-only
genetics reference.** Use the separate source-only packet first. Do not add this HTML,
these instructions, or candidate material to the source-only or mechanism share bundles.

After retaining a reviewer's source-only reference, provide `Candidate-followup.html`
and an assigned source-reference ID. The page is self-contained and works offline. It
contains the same 13 supplied excerpts and two original answers labeled Candidate A/B.
Statement text, limitations and original field/citation values remain as emitted; an
optional panel shows each original JSON answer verbatim. Neither invalid references
nor missing fields have been corrected. Reviewers need not interpret JSON syntax to
assess the narrative; they can mark traceability uncertain and explain why.

Ask reviewers to assess both candidates independently on seven parallel dimensions,
then record a preference, tie, neither, uncertainty or limits of expertise. Confidence,
source evidence and rationale are optional. There are no preselected judgments, scores,
model identities, parser verdicts or AI ratings. Candidate labels are neutral identifiers,
not a claim of random assignment or complete blinding to differences in presentation.

The header asks reviewers to confirm prior reference submission and disclose prior
candidate exposure. **This is a procedural gate, not access control:** candidate content
is already in the static file. The coordinator must enforce the separate-file release
sequence. If a file is released early, record that exposure; do not claim the subsequent
reference was obtained before candidate exposure.

Save follow-up responses with the page's JSON-download button before closing. Nothing
is transmitted or automatically saved. Return through the agreed channel. Exports are
`evaluation_only` and `unadjudicated`; keep them separate from agent-visible evidence.
Do not overwrite original source-only responses after candidates are viewed. Record
any later amendment or adjudication separately.

The internal assignment key and source/hash checks are retained under
`planning/review-assets/recovery-step7-20261026/followup-review/`; that directory is not
part of this share folder. Do not send the mask key or AI development triage to reviewers
during independent candidate assessment.

This is a prepared follow-up form, **not a human response or scientific validation**.
No new model call, external retrieval or biological fact was added to this form.
Static fidelity, blank defaults and export checks pass. Offline browser checks at
desktop and mobile widths pass, including downloaded dummy-answer readback; the
desktop candidate view and mobile save view were visually inspected. The QA exports
are explicitly labeled fixtures and are not human submissions. Retained evidence is
under the internal follow-up review directory. A form's completion label describes
entered ratings; the coordinator still checks reviewer identity, source-reference
receipt, independence and exposure before accepting a submission.
