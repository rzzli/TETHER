# Source-only genetics reporting review

Open **Expert-source-review.html** in a browser. The self-contained page works offline,
shows the supplied source excerpts, and downloads responses as JSON. Nothing is sent
or saved automatically. Save before closing; partially completed exports are allowed.

This addendum concerns the **genetics/MR reporting question** for the IL6R development
case. It is separate from the earlier mechanism review packet. It contains one offered
source record, all 13 extracted passages, the bound question and hypothesis, 10 review
items, optional confidence/rationale fields, and optional reviewer provenance, conflicts
and elapsed time. No answer is preselected and no score or answer key is supplied.

Use only the supplied material for the first independent pass. The full article was not
retrieved for this form. Missing source context can be reported explicitly; reviewers
need not reconstruct unavailable analyses or supply facts from memory. “Cannot assess”
and “Outside my expertise” are valid responses. Record any outside material or assistance
actually used rather than silently treating the review as source-only.

The coordinator should obtain independent source-only references before revealing any
candidate answers or facilitating reviewer discussion. Reviewers should disclose prior
candidate exposure. Returning a form does not automatically establish independence,
scientific agreement, MR validity, causality, or applicability to the intended antibody.

Response exports are labeled **evaluation_only** and **unadjudicated**. Store them in the
evaluation workflow, never in agent-visible source manifests. Keep the original export
unchanged and record any subsequent adjudication separately. The form sends nothing;
return the JSON through the channel agreed with the coordinator.

`planning/review-assets/recovery-step7-20261026/addendum-review/`. The only scientific

`prepared-request.json`; no candidate outputs, AI verdicts, evaluator keys, external
