# Installed P05 reconstruction adapter

Development version 0.1.0; qualification is unfinished. This separate distribution
uses the unchanged AsOf 0.3.11 core and PyArrow 21.0.0. It will reconstruct the
twelve native units and fourteen constructed controls from complete exact
originals and source-only configuration, then compare sealed outputs against
independently pinned historical hashes and metadata. No model is called.

The initial actual-source scope is Windows/Python 3.11. Source files, receipts,
roles, mapping/date guards and all physical matching rows remain mandatory.
Fictional tests do not qualify native Parquet behavior or Linux stable locking.

The public reconstruction manifest supplies its own new authority. It does not
verify unavailable old private journals/sealed trees. A sanitized role catalog
creates genuinely new reference fingerprints; only the independently approved
catalog-field projection can be compared with historical references. No digest
or verified-object identity is overwritten to imitate an old reference.

The package contains code only. Complete provider data, model weights, font files,
human responses and protected outcomes are not wheel assets. The source bundle,
neutral configuration and evaluator-only comparison authority are separately
allowlisted. This directory grants no publication or new acquisition permission.
