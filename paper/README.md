# TETHER working paper

[Read the PDF](tether-source-reporting-preprint.pdf) · [Manuscript](manuscript.md) · [Supplement](supplement.md)

This paper studies **literal source reporting and scoped verification**, not therapeutic prediction. Twelve selected source units and fourteen constructed controls test whether outputs preserve recorded values, missingness and provenance. Scientific and clinical validity remain unestablished.
