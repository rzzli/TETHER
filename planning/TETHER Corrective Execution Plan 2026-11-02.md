## Corrected objective and decision

The immediate objective is a clearly scoped, usable evidence-reporting platform with trustworthy verification and a technically accurate working paper. The existing result supports deterministic field reporting on a selected frame. It does not support target-ranking superiority, independent therapeutic expertise, a clinical probability, validated MR or general agent reasoning.

The owner has retired external expert responses as inputs. No recruitment, review panel or response gate is added. Owner names, declarations and acceptance remain deferred rather than invented. A versioned software fix, a new experiment and a new paper release are separate actions.

### Q03 Qualify data needed for a meaningful scientific task

**Completed as a reporting-only feasibility decision.** See the [Q03 assessment](<Project Progress Reassessment 2026-11-02 - Source Composition Feasibility.md>) and [independent source review](review-assets/tether-q03-20261102/review/INDEPENDENT-FEASIBILITY-REVIEW.md). The exact source-object join works, but selected missing study/variant/effect/cohort fields and source QC flags prevent stronger scientific claims. A deterministic baseline solves the task. The first failed audit's overwritten outputs and missing measured-code pins remain explicit; no new benchmark qualification is claimed. The following sequence records the decision criteria. No new cohort, answer set or experiment is frozen.

1. Choose one task requiring source scoping or multi-record composition beyond direct copying. Specify the expected answer semantics before examining candidate performance.
2. For a genetics-based task, establish upstream study, locus, variant, build, allele orientation, cohort/ancestry and sample-size identity first. The absent study table and unresolved composite join are explicit inputs, not fields to infer from locus equality.
3. Use existing subsets first. If new acquisition is needed, prepare the exact release, expected size, access/rights and storage/transfer plan; account-mediated files or new spending remain concrete owner actions when necessary.
4. Define how unknown units, direction, context and cohort overlap cause exclusion or abstention. Colocalization needs eligible dense regional summary data without significance filtering. Basic `coloc.abf` does not require an LD matrix; SuSiE and correlated-instrument approaches need appropriately aligned LD. MR needs method-specific valid instruments, harmonized effects, strength and overlap assumptions; a single-instrument Wald ratio does not require a dense regional LD matrix. None of these computational input conditions alone establishes causal validity. [Coloc input requirements](https://chr1swallace.github.io/coloc/articles/a02_data.html), [SuSiE requirements](https://chr1swallace.github.io/coloc/articles/a06_SuSiE.html), [Wald ratio interface](https://mrcieu.github.io/TwoSampleMR/reference/mr_wald_ratio.html).
5. For clinical tasks, separately qualify origin eligibility, publication/reporting windows, censoring, target-program mapping and source-supported outcomes. Registry completion is not therapeutic success.

**Done when:** representative original rows support every requested field and transformation; scientifically necessary unknowns are resolved or force explicit exclusions; eligible independent groups and missingness are counted. Otherwise retain a reporting-only task.

**Done when:** a neutral protocol, answerability/exposure/dependence register, faithful baseline and feasible resource envelope are fixed before new execution. No prospective claim is retroactively applied to existing exposed cases.
