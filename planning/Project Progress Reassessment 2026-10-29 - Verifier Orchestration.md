## Remaining implementation boundary

There is no live first-clock bootstrap, fixed root-authority loader, actual file identity/read/close adapter, output sink or real archive/journal/resource/core checker integration. Trusted checker ports are a declared boundary: a fake callback returning a typed observation is not proof of real evidence correctness. Owner tokens prevent accidental or serialized proof reuse; they are not hostile-Python isolation. Engine results explicitly say real profile qualification is false. No old payload was read or old verification gate rerun.

The next implementation must connect those parts under a reviewed prospective contract. It must preserve raw original-path identity and live leases, capture/hash the exact bytes subsequently checked, close only acknowledged ownership and include source/bootstrap work in one measured clock. Archive failure precedence, raw resource decoding and strict versus negative observer semantics remain real work. Passing a generic scheduler test does not complete them.

The earlier timing evidence remains endpoint-based: 153.094 seconds precede reservation, the reservation-to-close interval is 5.562 seconds, and the 134-second interval to the core audit has no recorded start. No isolated disk/hash/parser cost is inferred. The original whole-check expired at 300 seconds; neither source acceptance nor a later metadata-only archive audit repairs it.
