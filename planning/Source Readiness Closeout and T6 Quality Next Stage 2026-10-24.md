## Next planned branch: full T6/H5 quality

Clinical outcome failure does not block all T6 quality research. Source-supported
factual correctness can be assessed without a clinical scorer. Therapeutic benefit
and a human preference claim require different evidence. The user's approved
agent reviewers can build source-qualified references and judge development
quality; their judgments must be reported as AI judgments, not human validation.

The original T6 asks whether full dossier claims are true and supported for about
50 pairs. H5 proposes paired dossier preference on 40 pairs plus error and cost.
The completed top-one study instead selected one of two source IDs in eight tasks
over five cases. Its 6/8 versus 6/8 result does not answer either full objective.

An implementation inspection identifies a concrete next gate: `Backend.select()`
returns source IDs; `EvidenceLedger.append()` records `verbatim_source_selection`;
`artifacts.dossier()` renders those source statements. The local model does not
currently produce scientific interpretation, atomic interpretive claims or
claim-to-source entailment judgments. The existing adapted Virtual Biotech arm
has the same selection boundary. Comparing their prose preference now would
mostly compare a common formatter and selected annotations.

Proceed in this order, preserving current receipt/selection contracts:

1. Define a separately versioned **evaluation-only claim-audit contract** for
   atomic statements, source entailment, contextual applicability, contradiction,
   uncertainty and unsupported inference. Bind each judgment to exact source
   hashes and locators. A faithful annotation can still be inapplicable to the
   target/action/modality/tissue question. Include unresolved and not-assessable
   states; never turn incomplete collection into biological absence.
2. Validate the contract and paired evaluation rules with labeled fixtures,
   including opposing actions, modality/tissue mismatch, genetics-to-efficacy
   overreach, duplicated evidence, omitted context and uncertain source truth.
   These fixtures test the harness, not biological accuracy.
3. Specify an optional bounded interpretation layer, independently of
   `Backend.quote()`/`Backend.select()`, only after the audit boundary is sound.
   Keep generated interpretations distinct from admitted verbatim observations;
   preserve source provenance, budget journals and null clinical probabilities.
   Do not let new prose alter scorer features or archived run semantics.
4. Freeze a new source-only question frame, reference construction and paired
   analysis before outputs. Existing exposed cases are development fixtures.
   Neither the original ten cases nor the five top-one cases are a fresh holdout.
   Measure actual eligible pair and claim counts before setting inferential power.
5. Seal two source-only AI reviews and third adjudication before any model
   predictions. Retain all rejected/ambiguous questions and source limitations.
   Execute a small feasibility batch before scaling toward the original 50/40
   objectives. Report AI panel preference separately from factual source audit.
