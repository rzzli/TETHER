## Critical next major gate

1. **Freeze an own compiled harmless worker and build protocol.** Match the
   bridge's actual `/MD` CRT setting, not an assumed static-CRT build. Use only
   Windows APIs/standard library, explicit bounded arguments and cache output,
   pinned source/compiler/linker/dependencies and a fresh output directory.
   Source review and an exact decision precede compile/link. Building is not
   permission to execute. Preserve both Python failures as negative/unexplained.
2. **Qualify the compiled-child launch path once.** Predeclare resources,
   overflow, timeout and suspended-abort cases, unchanged caps, raw observations
   before assertions, ownership/resumption records and terminal seals. Keep
   generic total1 and only the deliberate rejected-child resource expectation
   total2. Independent verification must pass every case. A pass is specific to
   the compiled child and does not explain Python behavior or prove universal
   containment. An unexplained native count stops the batch; a separately
   reviewed bounded completion-port/PID observer is the next diagnostic, with
   no termination by observed PID and no inference from missing notifications.
3. **Only then prepare and run the fixed ABI observation.** A new exact helper
   and protocol must bind the existing EXE and four required runtime DLLs, use
   the qualified compiled-child path, record version/typed defaults/layouts and
   observed modules, and retain source-inclusive independent verification.
   No model paths, CPU registry, backend, vocabulary or grammar calls belong in
   this stage. Any mismatch stops; no fallback or automatic repeat.
4. **Separately qualify vocabulary/document/EOG behavior.** Bind the observed
   version, rebuild a recognition-enabled consumer, fresh-hash/read-lease the
   approved shards and preserve exact corpus bytes. Check tokenizer roundtrip,

   can be unavailable; do not manufacture replacements or count harness NUL/
   UTF-8 rejection as a native result. Single-candidate grammar checks do not
   measure full-vocabulary generation masking cost.

   retained simulation uses295.922/300s without inference. A source audit counts
