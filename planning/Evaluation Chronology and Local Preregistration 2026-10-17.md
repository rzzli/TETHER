# Evaluation chronology and local preregistration

The frozen protocol is `planning/protocols/evaluation-v0.1.json`. This is a local,
retrospective development registration and a gated clinical design. No public OSF
submission, locked clinical set, qualified clinical labels or independent review is
claimed. All existing 2023–2025 cohorts and the ten contemporary dossiers are exposed
development data.

## Selected model and windows

`b466e1f8c07172155743e8e1307507d8a4f91fbd`. The three pinned files total
8,988,110,496 bytes. Their LFS hashes, official repository commit dates, release
announcement and source responses are retained in the protocol/source-proof bundle.
The official announcement is dated September 19, 2024; the selected revision is
dated September 20. An exact training-data cutoff was not verified. Pre-origin
immutable weights, with no later fine-tuning or contributing later model, are the
chronology route. See the [publisher announcement](https://qwenlm.github.io/blog/qwen2.5/)
and [official quantized repository](https://huggingface.co/Qwen/Qwen2.5-14B-Instruct-GGUF).

The local machine reports 16,303 MiB GPU memory and 34,188,681,216 bytes physical
RAM. This supports attempting the selected quantization; runtime fit and speed
remain Task 4 measurements. No weights were downloaded or inference performed in
Task 3. Runtime binaries may be newer than origin: their hashes, flags and inference
must be retained, and they must not introduce later weights, retrieval or adapters.

The T6 pilot uses contemporary sealed data and the existing ten development cases.
It evaluates bounded evidence selection, provenance, failure handling and resource

The candidate clinical window is January 1, 2025 to January 1, 2026, twelve calendar
months, chosen for local archive availability and pre-origin model release rather

## Clinical activation gates

All seven gates are currently unmet. A versioned, artifact-supported amendment is
required before activation:

1. Select and seal origin-only programs, drug/arm roles, regimen, population, prior
   risk, exact mappings, exclusions and dependency components before endpoint joins.
   Previously inspected NCT/programs are excluded from a confirmatory candidate or
   the whole analysis is labeled retrospective development. Audit exposure overlap.
2. Qualify historical predictor files and all annotation ancestors, publication and
   availability bounds, including snapshot timing and reporting-delay limitations.
3. Establish independent reference labels and explicit censoring/negative rules.
   A recorded next-phase start is an enrollment/development surrogate, not success;
   missing registry progression is not a negative. Preserve unresolved links.
4. Repeat dependence-aware power analysis on the qualified new window. The existing
   2023-origin cohort does not reach the 80% planning target in tested scenarios.
   Do not transfer those counts to 2025 or inflate sample size using dependent arms.
5. Seal model outputs, prompts, seeds and all predictor artifacts before joining
   evaluator labels. Canaries and network/file capability boundaries must pass.
6. Validate downloaded model and runtime hashes and actual local execution.
7. Resolve the public-registration decision. This local file does not establish an
   OSF timestamp or prospective registration priority.

## Comparisons, hypotheses and stopping

H1–H6 retain the meanings in the original project proposal. No clinical superiority
test is activated. AUROC/Brier and calibration require qualified outcomes and scoring;
complete the multiplicity, censoring and component-bootstrap specification in the
activation amendment before any confirmatory label join. If gates fail, report
feasibility and descriptive development results without confirmatory claims.

All Virtual Biotech specialist, reviewer and chief-of-staff roles must use the same
eligible weights. Replacing the original models is an **adapted comparison**, not
unchanged reproduction. Match origin-filtered evidence and budgets; record missing
upstream datasets and tool deviations. Baselines are offline extraction and bounded
lexical selection; origin-masked association and genetics-only baselines are conditional
on qualified inputs. The original no-scorer/causal-genetics ablations remain conditional.

Keep $0 provider spending and current workflow caps. No account creation, paid query,
public submission or automatic uncertain-call replay is introduced. Stop clinical
execution on provenance, chronology, independent-label or power failures. Stop an
inference attempt on timeout/malformed output, preserving the journal and accounting.
AI review remains development assistance and cannot substitute for independent review.

## Validation

Seven chronology regressions cover future contributing models, mutable revisions,
later fine-tunes, missing reviewer roles, future/evaluator predictor sources, silent
current annotations, unearned lock/registration claims, timezone/order and tampered
proofs. The freeze binds protocol, source responses, archive qualification and existing
feasibility anchors. Task 3 completes the local protocol/chronology decision; the
clinical study itself remains gated and has not been finalized as a locked evaluation.
