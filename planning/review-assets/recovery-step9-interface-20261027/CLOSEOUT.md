# Pure interpretation interface closeout

Accepted AsOf 0.3.8 engineering slice, 27 October 2026. This completes the pure codec
gate, not the native adapter, scientific evaluation or full R09 step.

The new `source-quote-interpretation-v2` interface retains complete originals and
uses quote IDs bound to exact original source/path/text identities. Schema and
post-validation agree on answered/partial/abstained states, quote/text pairs and
active limits. Authored assertions remain unchanged; exact source strings are
materialized separately. Original R07 interfaces, failures and stop rules remain
preserved. Preparation is not source, history, token or dispatch authority.

The initial schema oracle exposed a Unicode nonblank mismatch in `\S`. The
corrected explicit whitespace set passes all 29 Python whitespace codepoints in
both claim text and reasons. The first broad focused invocation also hit a
sandbox C: temp permission/cleanup failure; clean focused and full validation use
D: temporary storage. Both failed reports remain retained. See
[development findings](DEVELOPMENT-FINDINGS.md). Code-author tests and an external
schema engine are not a new independent peer or scientific review.

The [public interface guide](../../../docs/INTERPRETATION_INTERFACE.md) describes
the API and limits. [Native adapter/controller integration](../recovery-step9-native-integration-20261027/CONTRACT.md)
is next: reuse the transport and existing shared-case controller, bind source/
history/capacity, account measured native usage, and preserve owned shutdown and
original bytes. Native schema-to-grammar compatibility remains unverified; no
permissive fallback or automatic R07 restart is authorized here.

Human reviews, fresh-frame/source sufficiency and scientific usefulness remain
pending. Historical clinical labels, genetics/scoring and the conditional later
programme are not completed by this engineering change.
