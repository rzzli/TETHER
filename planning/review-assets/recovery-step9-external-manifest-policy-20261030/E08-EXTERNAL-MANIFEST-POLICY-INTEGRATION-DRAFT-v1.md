# E08 external manifest policy draft

The proposed successor adds one kernel-defined immutable prebound binding and one mandatory same-Core policy check. Source3 and its 50-pass/three-deferred result stay unchanged. No policy code exists or ran in this task.

The first original clock observation and canonical Core/Origin/nonce/Registry precede this validation. Bounded detached binding/envelope capture then runs under that clock, before FileSpec admission, output callbacks, original opens or helper compilation. Execution binds the ordered basis IDs to the actual EntryPlan file pins and retains the existing captured import-DAG checks. A separately selected external TCB configuration supplies exact current IDs and external/prior root pins; an envelope role or ready flag cannot confer trust.

AUTHORING permits planned/unbuilt INPUT/CONSUMER nodes with null hashes and explicit reasons, returns AUTHORING_ONLY, and stops before output/source work. EXECUTION requires all submitted static nodes pinned and the graph consistent, then proceeds through the existing live file/hash/lease/output barriers. A report never authenticates the launcher, discovers a file, creates a native lease or authorizes execution itself.

Content-pin edges point from a dependent to its prerequisites. All declared nodes are checked. INPUT/CONSUMER ancestry cannot reach the current decision or output; self/mutual cycles are refused. Downstream decision/output provenance references to static inputs are distinct from making inputs depend on their future outputs.

The bounds are proposed metadata refusal limits: 256 nodes, 4096 edges, 128-byte IDs, 256-codepoint reasons, 14 current output IDs and 131072 canonical combined UTF-8 bytes. They cover the retained 48-node staging scale without claiming its future real roster is complete. They do not lift original7, native, physical, source/capture or time limits, and their logical byte allowance is not RSS.

The JSON contract fixes shapes, states, edge roles, binding comparisons, errors and ordering. The structural schema supplements those rules; generic schema validation does not prove the policy. Native owns independent literal outcomes; Grammar owns the finite peer. Freeze only after an explicit mutual FINAL_READY handshake. The exact files remain drafts until then.
