# Independent methods review: proceeding after a failed fictional answer control

**Recommendation: proceed once with the fixed all-199 public LitQA2 measurement under an explicit prospective amendment. Preserve the failed semantic gate.** This is defensible as a descriptive evaluation of the frozen solver and paired provenance policy; it is not a successful task-capability qualification.

This judgment is based on the reported actual fictional smoke outcome: native transport, complete session replay and owned cleanup succeeded, but the solver selected insufficient information on a trivially answerable supplied-passage fixture. It is the second reported semantic-control failure. This note provides an independent methodological judgment, not another execution or independent reconstruction of those smoke artifacts.

## What the control establishes

The current implementation can produce and verify native responses within the operational contract. The current solver configuration has failed the intended positive answer control. These findings must remain separately named. Do not retroactively call the entire smoke successful, erase unsuccessful attempts or infer strong reading/answering ability from valid JSON and successful receipt verification.

The failures warrant low expectations for useful answers. They do not, by themselves, establish that the source-access route or the entire benchmark is infeasible. A benchmark can validly measure a weak solver, including a negative outcome. It cannot guarantee a favorable result.

## Conditions for proceeding

Before actual benchmark retrieval and generation, amend the retained protocol to state:

1. Operational qualification passed; the fictional semantic answer control failed; benchmark scientific utility is unestablished.
2. All 199 public task IDs remain fixed. Freeze the exact model, prompt, grammar, source-selection algorithm, budgets and code before execution.
3. Produce each candidate at most once. Preserve every failure, unsure response, rejected candidate and unexecuted task on the full schedule.
4. Do not inspect interim native scores, retune prompts, replace the solver, discard difficult cases or stop because results look unfavorable. Existing operational/resource limits still apply and partial execution stays partial.
5. Score only after candidates are sealed. Report raw accuracy, answer precision with its denominator, coverage, correct-and-admitted/all scheduled, incorrect substantive admissions, native unsure and operational failures separately.
6. Label any source alignment as identity/retrieval coverage. Provenance admission does not establish entailment or correct scientific interpretation.

No minimum accuracy threshold or additional human gate is introduced by this amendment. The amendment changes how completion is described, not the recorded outcome of the failed control or the definition of a correct native answer.

## Completion and interpretation

**Measurement completion** means the fixed schedule has been executed or terminally accounted for, sealed, scored and independently reconstructed with its actual resource/operational outcomes. **Meeting the scientific task-capability gate** is a separate conclusion and is not implied by those mechanical steps.

An all-unsure result is a valid negative measurement: it has zero substantive-answer coverage, zero accuracy under this native task, and undefined answer precision reported with the explicit zero-attempt convention. Even if every unsure response passes the source policy, a 100% admission rate does not demonstrate useful scientific QA or a safety/utility improvement. Such a result leaves the existing semantic capability gate failed. Likewise, a run without actual generation cannot demonstrate answer-producing capability merely by retaining 199 failure rows.

If some substantive answers are produced, report their measured native correctness without treating a few successes as evidence of broad competence. A high incorrect-admission rate would expose the declared policy's semantic limitation rather than contradict its narrower provenance checks. This study must not claim superiority, improved entailment or strong scientific reliability from acceptance rate alone.

The all-199 run can therefore finish the planned measurement while yielding a negative scientific finding. Preserve that distinction in the results, milestone status and manuscript. Any later solver improvement belongs to a separately declared experiment with its own exposed-data limitations; it must not overwrite this baseline.

No benchmark calls, model calls, score computation, source changes or new external review requirement were made for this methods judgment.
