# Independent BG04 operational audit

This helper uses only the Python standard library. It does not import `collect`, `run`, their verification functions, or other project implementations. It dispatches no network/model/process work and opens no benchmark original, reference or provenance product. The parent owns source collection progress; this is a bounded independent audit, not periodic monitoring.

`audit.py` verifies the externally supplied freeze hash, frozen source/driver hashes, hash-pinned command recipe and policy, task-only query bytes/schema, complete 199-task schedule, journal chain, and durable terminal-case identities. For completed cases it reconstructs HTTP attempts and body-byte charges from original bytes/receipts, distinguishes known bodies from conservative failed-transfer reservations, checks selected UTF-8 text hashes and original character bindings, and reconciles per-case totals. The model-accounting primitive independently separates measured usage, conservative estimates and unresolved dispatches; actual generation auditing remains a later step.

The active journal is captured as a fixed byte prefix. Only cases with durable terminal events in that prefix are opened. Pending cases are neither failed nor assumed complete. Source contents are used for hashes/slices without interpreting or displaying biological answers. No statement about source relevance, entailment or native accuracy follows.

## Later gates and limits

After the parent supplies the completed collection's external seal, audit final completeness, aggregate totals and complete artifact inventory independently; qualify any additional analyzer logic in a separate version. After generation is sealed, independently audit all-case native dispatch/accounting and source/recipe/candidate identity without using producer verification functions. Reference-dependent native scoring belongs to a separately authorized reconstruction after generation seal.

Known body bytes exclude headers, TLS and wire overhead. Unknown/failed transport reservations are conservative bounds, not measurements. The current qualification does not attest the entire host, inspect live model memory, replay scientific XML interpretation or prove semantic support. Production experiment code is unchanged and held at the supplied freeze.
