P05d deterministic source-validation experiment and analysis plan, version 1

**Status: DRAFT; no execution authority and no results.** Prepared 1 November
2026 from code, value-free plans and public technical metadata. Neither actual
reference values nor generation-packet row values were read for this design.
The companion `EXPERIMENT-PLAN-DRAFT-v1.json` makes the proposed schedule explicit.
Its unresolved reference, code, fixture and denominator seals prevent a READY
lock. This document changes neither the core API nor any preceding protocol.

**Implementation clarifications, 1 November 2026; still DRAFT.** The fourteen
fictional scenarios use generic JSON originals, real fictional contemporary
receipts and unchanged core guards, plus the applicable pure P05 normalization,
date and exhaustive-inventory predicates. They do not claim a successful native
P05 Parquet input build: that unchanged scanner requires every measurement
column, so C02's absent SE is specifically a generic core absence control. The
native path retains that complete unchanged scanner/wrapper policy. Strict exact
reporting requires `status: answered` and every requested slot, including unknown
slots; core 80% completion may still pass a partial-status report or an omitted
unknown, which are rejected by strict exact reporting. Fictional qualification
runs are preparatory test artifacts with all native outputs explicitly
unexecuted; their repeated tests do not enlarge or execute the locked study.
These clarifications preserve fourteen scenarios, 38 outputs, 90 decisions,
the fixed twelve-unit native denominator, resource limits and zero run authority.

**Question and claim.** Can the frozen deterministic workflow preserve and
independently verify literal native field reports across twelve selected source
units, expose native missingness, and distinguish deliberately invalid inputs or
reports from valid ones at their declared guard stages? The endpoint is technical
source fidelity. It does not test biomedical truth, causal genetics, study
quality, intervention direction, clinical prediction, expert agreement or model
superiority. P04/P04b remain closed negative development evidence. No model arm,
prompt retry, cohort expansion, external expert or new acquisition belongs here.

**Fixed source frame and observational unit.** Use exactly `p05-01` through
`p05-12`, in the sealed identity-hash order; no replacement, reranking or selection
by numeric availability, future scores or ease of execution. The registry covers
137 retained originals (2,866,248,239 compressed bytes), with 1,753,850 physical
GWAS rows, 1,681,738 policy-eligible and 72,112 excluded. These are source-policy
counts. The twelve selected units each have one eligible physical GWAS anchor and
one eligible credible row at an exact native locus key. `INPUT-AUDIT-v1.json`
reports `PASS_ORIGINAL_SOURCE_INPUTS_AND_NEUTRAL_TASKS`; its per-case metadata
records two task records, fifteen requested fields and one measurement group.

Every unit requests eight GWAS identity fields, three credible-row identity
fields and four native credible measurements (`beta`, `standardError`,
`pValueMantissa`, `pValueExponent`). Thus there are 180 requested fact slots,
132 identity slots and 48 measurement slots before reference qualification.
Those are request counts, not answerable denominators. Each credible row forms
one measurement group. Its answerable component count is established by the
independent reference replay, never inferred from the existence of a locus ID.
The already public summary records missing beta in 1/12 and SE in 7/12; it does
not authorize assuming all other measurement components are answerable.

The join is locus-only `one_to_many`, retaining every eligible physical match.
Native study/variant agreement across sources remains unresolved for all twelve.
No locus match verifies an upstream study, variant equivalence or gene effect.
Action, modality and tissue remain null; target/indication namespace versions,
units/scales, allele orientation, genome build, study/cohort context and ancestry
remain unknown unless literally supplied by the already frozen task. No context
is transferred from an anchor to a linked statistic. Receipt-bound contemporary
eligibility at `2026-11-01T07:16:26.101448+00:00` is distinct from first-public or
historical availability. Missing row dates remain unknown.

The nine previously named exposed symbols remain excluded under the registry
policy. All other project exposure is `UNKNOWN`; the cohort is not certified
fresh or a holdout. The unit is a selected native source identity, not an
independent study. Before READY, retain case IDs, release/source/physical-row
identities and native study/variant/locus/target/indication dependence keys in an
evaluator-only register. Mark shared records and equal keys as observed
relationships, possible study/cohort/article/family links as unresolved, and
absent study/article/cohort mappings as unknown. Equal native strings are not
verified cohort identity; unequal strings do not prove independence. A shared
release or shard is an engineering dependency. Do not manufacture biological
families or study independence from it. This design uses descriptive paired
analyses even if a later register supplies more relationships.

**Separation and freeze.** Generation uses only the independently audited sealed
original-only packets, neutral tasks and their eligible original ancestry.
References are constructed separately from fresh original reads plus the sealed
value-free tasks, never from packet values. The reference builder and wrapper
may share guard/scanner helper algorithms with the input builder; this is not
independent algorithmic evidence. The actual source audit must independently
project originals, locators, eligible/excluded inventories, normalization,
precision-aware dates, literal fields and missingness, without importing the
producer's selection or projection functions. Retain common-library dependence
as a limitation. AI audit is a technical secondary check, not external scientific
adjudication.

No old answers, private gold, human returns/addenda/ratings/normalizations or any
answer-aware descendant, protected clinical originals, P02 selected-row products,
stage1 SQLite/capture/mapping/coverage values, evaluator references or reference
derivatives enter generation, task selection or tuning. Fault fixtures are wholly
fictional and never modify a native original or its receipt. A fictitious
`evaluation_only` ancestor tests a role guard without using an actual prohibited
artifact. Neutral configuration stays outside the evidence graph.

A separate immutable READY must bind, before any baseline or fault output:

1. The exact twelve-case inventory and full exposure/dependence register; original
   and receipt pins, approved roots, registry/input/task seals and independent
   input audit; the unchanged cutoff, eligibility, field, grouping and join rules.
2. The independent reference manifest and its externally retained hash; all
   per-case compiled/blocked dispositions and source-inclusive audit; counts of
   answerable/null/empty/absent/join-withheld facts and groups by family and case.
   No values are required in the public schedule. Reference failures remain in

3. Exact experiment-local assembler, fixture authoring, guard invocation,

   inspecting results and silently reused under the same version.
4. All 38 output cell IDs, 90 decision IDs, case/task/reference associations,
   fictional source/task/receipt/fixture hashes, fixture truth labels and expected

5. An exclusive new ignored output directory and externally retained READY hash.
   The complete schedule must exist before its first cell. A lock with null pins,

   cases are explicitly scheduled as unexecuted outputs and no-decision verdicts.

**Implementation boundary.** The existing `source_fact_reporting.reporting_view`
and `literal_report` implement the P04 EuropePMC/no-join packet, and reject P05's
packet type and joins. The current cell runner is also not a qualified P05 runner.
Do not claim those functions already run this experiment. A small P05-only
experiment script must authenticate the P05 packet, read its supplied native rows
and value-free slots, and emit literal `typed_facts_v1` bytes without opening a
reference. It handles only the frozen one-to-many locus task and fictional
variants, preserves exact types/order/signed zero and absent/null/empty reasons,
and fails on unsupported shapes rather than adding a general framework feature.
The abstain control emits no facts, preserves the task/collection binding and
states deliberate abstention. It receives the same legitimate input. The
assembler has no reference-valued argument and cannot read evaluator paths.
Use existing `validate_task`, `adapt_output`, `compile_reference`,
`verify_reference`, `score_cell` and `aggregate_cells` unchanged where their
contracts apply. Keep core and earlier pinned protocols unchanged.

**Guard stages and diagnostic policies.** The stages below separate byte custody,
source qualification and report correctness. Record the first failed stage, all
actually attempted later stages, and precise exception/rejection reasons.

| Stage | Required evidence |
| --- | --- |
| G0 retention and identity | External READY, scheduled task/code/environment, artifact hashes and bounds; original/receipt hashes against their independently frozen source pins. Fixture integrity pins preserve a constructed test, not source-policy legitimacy. |
| G1 provenance | Trusted roots; original/receipt identity and chronology; complete ancestor roles/deny policy; no evaluator ancestry or role laundering. |

These are logical guard categories, not claims about separate existing process
entry points. Attribute native type/representation preflight to G3 even when
the current wrapper invokes `native_representability` before its compiler call;
retain that actual function/stage in the journal as well.

`FULL` requires G0–G4 for verified reporting. `WITHOUT_WRAPPER` omits only G2 from
its diagnostic admission, retaining G0/G1 and every unchanged G3/G4 core guard.
It shows the contribution of the newer eligibility/inventory wrapper beyond the
base compiler. `WIRE_ONLY` retains G0 and output schema/bounds from G4, and omits
source qualification and factual matching. It demonstrates what parseable bytes
alone admit. These are deliberately weakened local decision policies, not usable
clinical methods, qualified source validators or new product modes. Their
acceptance labels are diagnostic and never confer a `VerifiedReference` or
biomedical endorsement. Do not describe their comparison as superiority over the
original complete framework.

Use policy-specific calls to unchanged guards or a frozen policy projection of
retained guard outcomes, with the exact mechanism pinned before READY. Do not
monkeypatch core checks. If a residual core guard catches a fault in an ablation,
retain that outcome; do not disable an additional guard to obtain the expected
difference. No fabricated `ScoredCell` or score is allowed when a policy has no
source-verified reference. Expected outcomes below are hypotheses of these exact
fixtures, not assigned results.

**Fixed schedule.** Emit exactly once for each native case: `N-L-p05-XX` (literal)
and `N-A-p05-XX` (always abstain). Evaluate the same retained literal bytes under
all three policies, and the abstain bytes under FULL: 24 output cells and 48
decision cells. Run the fourteen fictional scenarios below once each, retaining
one output or explicit non-return record, and evaluate each under all three
policies: fourteen output cells and 42 decisions. This gives **38 output cells,
90 verification decisions, twelve native units and fourteen constructed
scenarios**. Reusing bytes across policies is explicit paired evaluation, not
additional generation or independent replication. Do not cross every fault with
all twelve native cases. No empirical invalid-input prevalence is estimated.

All fictional sources use invented IDs, predeclared clean dates and the same
null intervention context. C01 has native measurement components `1.25`, `0.25`,
`2.0`, `-6` with native float/float/float/int types. C02 replaces beta with native
null, omits the SE schema field and makes mantissa an empty string; exponent

different native study/variant IDs; its second native SE is `-0.5`. C04 makes all
four measurement components native null but retains answerable identities. These
are invented numbers, not values from any actual case. C03 deliberately shows
that finite native SE and locus reporting do not validate scientific plausibility
or composite study/variant identity.

The fictional producer deliberately constructs **untrusted candidate attempts**
from its frozen invented recipe, even when the associated source is intended to
fail admission. A candidate may therefore have a `returned` raw-output terminal

separates ability to inspect a candidate from permission to accept it; an
admission failure does not erase retained candidate bytes. For F01 retain both

experiment manifest authenticates the intended altered fixture, while G0 must

The fictional oracle is independently authored from these descriptions before
execution, with source field presence/types, inventory membership, fault locus,
expected reasons and stage recorded. It must not be generated by calling the
same assembler/compiler under evaluation. A reviewer checks the frozen fixture
bytes and oracle directly. Encoding-level fixture tests are preparatory tests;
their repetitions never enlarge the experiment. No partial output is substituted
for a failed exact assembler. An expected result that fails to materialize is a
finding or test-design failure, not a reason to relabel/retry the scenario.

**Endpoints and denominators.** The native co-primary descriptive quantities are
(a) FULL acceptance of complete exact literal reports out of the fixed twelve
native units and (b) FULL 80% measurement completion out of the same twelve.
Report separately how many units have an established nonzero answerable
measurement denominator. A zero-denominator case cannot complete the measurement
endpoint; retain its null coverage/pass and separate exact-report result. Cases
blocked before scoring remain failures/unexecuted in twelve-unit accounting,
with unknown exactness, not zero-valued source coverage. Also show results among
qualified nonzero-denominator cases with that explicit secondary denominator.

An exact report emits every requested fact once and matches all value/unit/source/
unknown-reason bindings and collection disposition. Its canonical semantic match
does not require the source's original JSON lexical spelling or byte sequence.
End-to-end verified exact acceptance additionally requires G0–G3. Report raw
return, schema-valid return, exact report and verified acceptance separately.
The protocol's 80% completion is weaker than exact reporting and cannot substitute
for it. The always-abstain control should have zero unsupported assertions and
zero completion on answerable tasks; compare its factual coverage and abstention
to the literal output without presenting its lack of errors as successful
reporting. Completion is not an appropriate sole negative-control endpoint.

Within each case, use unchanged equal-weight answerable-group coverage:
`mean_g(matched_answerable_components_g / answerable_components_g)` over the
predeclared `reported_measurement` groups. Unknown-only groups have no denominator.
Report raw requested, answerable, matched, omitted, correctly unknown and falsely
asserted fact counts, answerable/unknown-only group counts, all native unknown
categories, critical-error types, and identity/measurement family coverage.
Unknowns earn no measurement credit. Also give the descriptive fraction of
requested measurement slots that are answerable, to expose sparse native inputs.
Do not replace native unknowns with zeros, count them as successes, reconstruct
p-values or compute effect estimates. Mantissa/exponent remain two literal
components in the existing group; their partial return is not a valid atomic
scientific p-value. Show 60%, 80% and 100% threshold flags without retuning.

For the constructed controls, show every scenario's verdict and earliest failed
stage by policy. For each policy, technical false acceptance is admission of a
fixture labeled INVALID (ten planned scenarios), and false rejection is rejection
of VALID_REPORT (four planned scenarios). Give counts over planned scenarios and
over actually attempted decisions, plus unknown/no-decision counts. An unexpected
program exception, timeout or unexecuted decision is not a successful rejection.
Report C04's correct zero-denominator handling separately; rejecting its
measurement completion is not rejecting its valid source report. C03's technical
acceptance cannot become evidence for valid SE, independent studies or causal
identity. Show native legitimate exact-report rejection counts separately from
the fabricated invalid fixtures. The diagnostic policies are compared on the
same bytes using paired discordance tables and named failure mechanisms.

Byte-integrity outcomes (hash/receipt/retention), semantic outcomes (literal typed
facts and bindings), and scientific-validation status are separate table columns.
Scientific validation is `not_established` for every native case and is not
rescued by byte integrity or 100% semantic coverage. No semantic-entailment or
clinical label is fabricated for the experiment.

No binomial confidence interval, significance test, power claim or twelve-study
generalization is planned: selection is a finite identity-ranked source frame,
dependence is unresolved, and the fault scenarios are designed rather than
sampled. Native comparisons use paired case displays, discordance counts and
descriptive coverage differences; report range/median across cases when defined.
Repeated policies, facts and fictional faults do not inflate the independent
denominator. A future independently justified inferential design would be a new
protocol, not a post-result addition to this one.

**Terminal accounting and limits.** Every one of the 38 scheduled outputs gets
exactly one `returned`, `malformed`, `failed`, `timeout`, `interrupted` or
`unexecuted` terminal. Keep `received_terminal` distinct from adapter disposition.
Every decision gets exactly one admitted/rejected/no-decision verdict, stage and
reason plus a terminal status. Admission failures are not malformed output, and
partial bytes never rescue a failed process. Preserve all attempt directories,
exceptions, source/reference pins, bytes/hashes, journals and failure seals.
No automatic retry, rerun, continuation into a used directory or unrecorded
replacement is allowed. On budget/global failure stop and explicitly mark the
remaining schedule unexecuted. A later authorized correction requires a new
version and retains this attempt; the planned denominators do not disappear.

Use a P05-only outer ledger for all 90 decisions. The unchanged core aggregator
requires valid task/reference hashes and source-verified objects; use it only for
its genuinely scoreable, prespecified subset. Keep upstream blocked/reference-
absent cells in the outer schedule and twelve-unit denominator rather than
inventing a reference, `ScoredCell` or numeric coverage to satisfy that API.
The independent final audit reconstructs both ledgers and checks there are no
missing, duplicate or unscheduled cells.

**Interpretation and baseline ceiling.** Conditional on legitimate, complete,
representable packets and independently correct references, the literal
assembler's declared ceiling is 100% of answerable facts/groups with exact
unknowns; its task is copying. Always-abstain supplies no factual coverage and no
unsupported fact assertions. These analytic ceilings are not empirical P05
results. Verify them on the locked cases and report any departure as an
integration, source, reference or implementation finding.

The native replay adds a bounded empirical integration check over independently
selected real physical records, actual-format rows/receipts, multiple files,
real missingness and complete source-to-packet-to-report custody. It can expose
differences between simulated controls and retained-source behavior, practical
resource costs and false rejection of legitimate reports. It is not twelve
independent biological replications. Because all twelve currently have the same
simple one-anchor/one-match structure, a clean perfect result alone has little
scientific novelty beyond engineering replay. The fictional controls establish
only behavior for their named constructions and can overlap existing unit-test
coverage; they do not estimate natural corruption prevalence or broad validator
sensitivity. If native replay is uniformly trivial and fault behavior only
restates existing tests, the honest paper contribution is a reproducible bounded
technical artifact with negative model-development evidence and explicit limits,
not a validated biomedical method or a new general validation framework.
