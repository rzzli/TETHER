# Release replay prerequisites identified before the experiment

Status: planning only, 1 November 2026. P09 remains pending. This note grants no
new acquisition, publication, installation or replay authority.

The retained P05 reference wrapper deliberately verifies its exact reviewed
code/environment and local trusted roots. Its READY binds the interpreter path,
Windows environment, original E: root and current workspace output root. Current
experiment orchestration also explicitly accepts that same original root.
Neither qualification establishes a relocated or installed replay of the actual
P05 study. The unchanged core source-reference API supports independently
approved logical source relocation; the newer wrapper adds stronger local policy
and must not be silently bypassed to claim equivalent full verification.

Before declaring the paper artifact complete:

1. Identify the public package's supported replay scope: portable fictional
   controls, installed core/baseline replay, and actual-source reproduction with
   the full pinned originals. State their separate requirements and guarantees.
2. Inventory imported code and schemas, interpreter/dependency versions, exact
   catalogs/receipts, query definitions, protocols and licensing. A selected-row
   extract cannot impersonate its full original file/hash or complete inventory.
3. Decide how legitimate approved-root relocation is represented while preserving
   logical identities, source/receipt hashes, roles, complete eligible ancestors,
   normalization, temporal guards and independent hash anchors. Retain old
   exact-version verifiers and original failures. Any new replay implementation
   is separately reviewed/versioned; it cannot retroactively alter an old run.
4. Run installed tests outside the checkout without importing `src` through a
   source-tree path insertion. Declare fictional versus actual-source scope and
   optional Arrow dependencies explicitly. Do not substitute a JSON-only smoke
   for successful actual Parquet study replay.
5. Check lawful redistribution before copying source subsets or originals. If
   external originals are required, retain exact acquisition manifests and clear
   reconstruction instructions. This phase authorizes no new download.
6. Reproduce analyses from pinned audited results, qualify supported relocation,
   and run the relevant complete release checks at one exact code SHA. Measure
   resource cost and CI budget; older 1,774-test acceptance is not that result.
