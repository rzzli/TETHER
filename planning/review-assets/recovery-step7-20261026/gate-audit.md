Preserve old failed runs and prepared payloads. R05 acceptance is preparation only; R06 is recorded smoke, not a native execution receipt.
2. **Native consumer and offline replay verifier:** the packaged CLI currently has no native mode. Add the minimal bounded loopback adapter and explicit trusted verifier for native request settings/response binding, completeness/stop causes, measured usage, retained bytes and post-validation. Do not pass a native response through `RecordedVerifier`, call fixture usage measured consumption, repair outputs, or launch another converter-search loop. 3. **Real ownership and resource admission:** reverify approved existing asset hashes; bind the exact executable, weights, context, offload and command. Supply positive OS listener ownership before health and generation and cleanup only the retained owned process. Actual startup must establish configured context and available resource headroom; fake tests cannot do that. Measure runtime/memory where supported, otherwise retain null/reason rather than estimates presented as measurements. No stronger-model download or paid access follows from this audit.
4. **Source and evaluator separation:** revalidate the real request's retained source/provenance bindings through its supported admission/archive route; a matching prepared request hash alone is not a fresh source-inclusive verification. Synthetic controls remain explicitly invented fixtures with no real source-admission claim. Freeze source-only requests; exclude prior candidate outputs, human references, AI adjudications and synthetic answer expectations. If a real source dependency cannot be verified, record that cell as blocked; independently runnable synthetic cells need not be discarded.
5. **Aggregate execution bounds:** at most A/B once per case; temperature 0 and seed 42 as frozen; prompt 14,200 UTF-8 bytes, complete HTTP payload 65,536 bytes, output 2,048 tokens, context 16,384. Respect shared 32,000-input/8,000-output/16-call/300-second/$0 case defaults, with the declared diagnostic narrowing to two calls and at most 150 seconds per arm. Respect the R05 overall 20-minute diagnostic ceiling including lifecycle. Do not reset the parent budget per cell, omit failures from denominators or retry to obtain a parseable answer.
6. **Seal before access/review:** record exact responses, config, journals, measured versus conservative usage, timing/memory and server termination. Verify mechanically, retain unsuccessful cells and mark human review pending. Do not show candidates to recruited reviewers before their independent source-only submissions. Do not describe technical completion as scientific acceptance or automatically expand to twenty cases.
