training/evaluation cohort or establish scientific truth from agent agreement.

These are qualification counts, not clinical event rates. No events were inferred
absent, no unknown was converted to a negative, and no origin member was removed.

checks confirmed all twelve members at every snapshot, generated query/source

PFS timeframes, selected LPP versus overall LPP/FFA eligibility, conflicting
