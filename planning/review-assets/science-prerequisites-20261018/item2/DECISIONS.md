This item establishes source-grounded evaluator references before new system arm
outputs. It does not estimate superiority or certify independent biological truth.
Actual matched AsOf/Virtual Biotech runs and workflow ablations belong to Item 7;
requiring them in Item 2 would create a circular implementation dependency.

The original twenty reviews were retained and crosswalked against current sources.

scientific context changes. Existing ratings are not automatically copied.

Two fresh-context agents independently research all ten cases without arm outputs,
prior reference answers or each other's answers. Initial records must be sealed
before third-agent adjudication of disagreements and a fixed agreement sample.
Shared model-family errors remain possible and unmeasured. Unexposed exact model
revisions stay null with a reason and execution identity.

Original-row fidelity (Q1) and external intervention/modality context (Q2-Q4) remain
separate. External review uses information public by October 18, 2026; it does not
enlarge the agent-visible Open Targets 25.09 source world, qualify historical
predictors or turn associations into intervention effects. Access depth is explicit;
HTTP success alone establishes neither accessible full text nor correct assertions.

Deterministic pre-arm sampling stratifies populated categories and preserves whole
observations. Provider scores are not truth weights. Unknown/unavailable/failed-QC
inputs stay explicit. Original physical rows are checked against receipt-verified
bytes. Numerical prediction features remain empty and real probabilities stay null.
