# Captured archive checker: effective v3 scope

The effective preparation basis is `CAPTURED-NATIVE-ARCHIVE-CONTRACT-v3.json` (ce077d5b), its 32 frozen synthetic fixtures (3e75447d), and preparation acceptance 629216db. Historical `FORMAT-MAP-v1` material is not the rule for every late failure history.

A normal `post_receipt_lease_cleanup` supplement belongs in the later terminal map and its explicit late-failure pin. A `post_lease_cleanup_or_terminal_sealing` exception supplement may instead be added after an earlier terminal record. Its absence from that earlier record's map does not alter the earlier publication bytes; the supplement still vetoes a positive outcome and leaves the captured graph incomplete. An after-seal marker similarly preserves and references the earlier seal while retaining a negative source disposition. Missing early fields, including an unknown return code or an empty original-lease roster, remain unknown; the checker does not invent completed observations.

`captured_archive_v2.py` checks immutable, caller-supplied bytes and declared metadata. It performs no filesystem lookup, path opening, API call, original authentication, directory reconstruction, complete journal validation, resource validation, or profile qualification. Opaque child result bytes are hash-linked without becoming accepted child semantics. Every corresponding qualification flag remains false, including when the captured graph is consistent.

The first v1 pure run passed nine methods and all 32 projections. Subsequent self-review retained two concrete counterexamples in `CAPTURED-NATIVE-ARCHIVE-SELF-REVIEW-BEFORE-v2.json` (bd5fc7f8): an injected `ValueError` was mistaken for invalid JSON, and a child marker with an additional actual LF was accepted after its dependent maps were coherently rebuilt. The separately named v2 source preserves callback exception identity and requires one actual terminal LF with no other actual LF/CR in a JSON document. Its ten methods pass all 32 projections plus these regressions. These are synthetic source/pure observations, not a replay or qualification of an old archive.

The source, checker, proof, before evidence, exact byte transformation, and unchanged AST comparisons are pinned in `CAPTURED-ARCHIVE-CHECKER-FREEZE-v2.json`. Independent peer review remains separate.
