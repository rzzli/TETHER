**Revise the source locator roster before fixtures or checker code.** Contract
`e77f8510…` allows root`journal.jsonl`, omits`execution/journal.jsonl`, and omits
root`parent-reservation.json`. The retained reservation function writes the
reservation first and constructs its journal under`output/execution`. A normal
positive captured archive must include that reservation and its exact schema.

The post-terminal exception-late correction is coherent when kept narrowly
negative/incomplete. Such a supplement may be absent from an older seal map;
it establishes neither a successful terminal return nor exact chronology.
Normal late markers still require their source links. Terminal-publication and
journal-close error supplements precede the sealer and belong in a retained
normal terminal map, while possibly remaining absent from an earlier receipt.

The proposed separation of captured graph integrity from source outcome and all
qualification claims is sound. Malformed root/child failure filenames must still
veto; no flag inside them can disable the veto. Missing seal/evidence, child
partial/final conflicts, self/future/cross-root edges, direct role collisions and
finite caps require literal expected outcomes before implementation.

Only new design metadata and narrow retained source text were read for format.
No old run was replayed, no original source was hashed or qualified, and no input
leaf, payload, SDK, native API or compiler was used. Captured-universe closure
cannot prove actual-directory completeness. Child results, journal semantics,
resources, owner provenance and profile acceptance remain separate pending gates.
