# BG05 final coverage — complete with declared gaps

All 27 obligation families have conforming original archive cases across the three matched arms and three repetitions: **981/981 scheduled cells**. The separate runtime experiment retained **19 logical dispositions**, all matching their intended controls under independent reconstruction. These are bounded conformance results, not complete production-runtime or scientific equivalence.

The primary population is 109 exposed authored cases, repeated nine times across conditions. Runtime controls contribute zero additional primary cases. The ownership race uses two workers for one logical case. The runtime outcomes are four completed, three budget-exhausted, nine errors, one timeout, one interrupted-unresolved and one deliberately unexecuted follow-on case. An expected error is a successful fault control, not a normal completed model answer.

Evidence: [primary independent reconstruction](../reconstruction/actual01/RECONSTRUCTION.json), [runtime independent reconstruction](../reconstruction/runtime-actual01/RUNTIME-RECONSTRUCTION.json), and the exact function/log proof index in [the companion JSON](RESULT-COVERAGE-FINAL.json). The earlier draft, normative matrix, design, frozen code and outputs remain unchanged.

## Remaining limits

- Full eight-specialist T1/T6 scheduling is not ported.
- Positive selection-review retry is not ported; native review/model/sample retries are explicitly zero.
- Live schema-two use/frame/grant facade and complete therapeutic renderer equivalence are not claimed; their original artifacts are validated in the archive suite.
- Parent process supervision reuses qualified installed TETHER code; it is not a wholly TETHER-free or native-Inspect process boundary.
- General source eligibility uses the reused independent validator; the runtime reader independently joins source rows/claims but does not implement a third general eligibility algorithm.
- Independent feature/prediction replay covers all eight slots only under the declared genetic-support synthetic fixture; generic feature engines, other feature schemas and clinical calibration are outside scope.
- IX11 write failures are maintained component/mock qualification; no new persisted native write-fault scenario was executed.
- Controlled two-worker ownership and direct-child interruption do not establish universal filesystem race safety, arbitrary descendant containment or power-loss durability.
- Trusted Python network audit hooks are not an OS sandbox; the Windows stdlib asyncio loopback exception remains explicit.
- Injected commit-clock expiry is a contract witness, not measured performance on long scientific workloads.
- Parent proof and final-seal work is measured but not hard-preempted; postexecution anchors are not independent timestamp attestations.
- Exposed authored cases and repeated batches are not independent natural faults or scientific-quality benchmarks.
