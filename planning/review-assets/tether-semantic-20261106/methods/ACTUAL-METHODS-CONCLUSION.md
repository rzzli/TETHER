## What this permits next

The baseline's poor complete-answer result is not explained by retrieval coverage alone. A fixed-retrieval stronger joint solver is a justified next prospective comparison because it tests document abstention/selection, labels and rationale extraction on the same available documents. That comparison still changes model supervision if it uses an external checkpoint; it cannot be called a matched architecture ablation without additional controls.

No count above estimates the accuracy gain from a hypothetical repair, and no diagnosis authorizes dev-gold tuning, dropping hard cases, changing the 300-claim denominator or replacing the native metrics. Evidence-use interventions remain separately labelled diagnostics. A weak stronger-solver measurement can complete its own stage; it cannot remove the subsequent authorized LitQA2, ALCE, ScholarQABench or R2E work from scope.
