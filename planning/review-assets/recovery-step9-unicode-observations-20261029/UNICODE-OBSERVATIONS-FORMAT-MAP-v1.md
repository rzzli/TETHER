# Complete Unicode observation validator proposal

The missing component should inspect captured JSONL and an optional captured child failure marker, using the exact factory-issued new profile. It should expose separate observation and strict-success operations. Neither operation grants profile, source, runtime or scientific authority.

The frozen tables already define the complete normal order: 15 setup rows, 84 before/result pairs, coverage and selection, up to four unique selected-prefix results, then cleanup, batch and normal completion. Actual success has `188+U` rows. The larger 276-row reservation does not permit extra cases, unknown events or a 64 KiB footer exception. The proposal references the frozen tables directly instead of duplicating their schemas.

The validator must commit each case only after its exact body, source references, native accounting and geometry checks. It must recompute all supplied-piece counts, population, first selectors and de-duplication with the accepted analyzer. Token rejection and mixed EOG retain valid geometry. Harness exclusions, known zero and unknown remain distinct. Prefix controls replay the original tokens; they never retokenize or search for another favorable boundary.

Success, complete negative collection and partial evidence are separate. A complete negative collection can retain all 84 cases and a known terminal failure without pretending unobserved controls or success footers ran. A truncated tail, pending native call, missing row or unknown cleanup remains partial. Failure-marker presence vetoes before malformed contents can hide it. External archive, parent, resource, source and clock gates remain independently necessary.

Callback exceptions must preserve their original identity. Required checks and bounded byte/hash operations stay outside data-decoding catches, including UnicodeError-family handlers. The design creates or resets no clock and claims no single-operation preemption.

Before implementation, freeze one complete fictitious positive trace and bounded negative/partial/mutation traces using all actual source cases, stages and grammars. Synthetic pieces and outcomes are engineering fixtures, never native observations. Existing isolated framing rows are insufficient. Root review of this proposal precedes fixture generation or validator code.
