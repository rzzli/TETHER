# Pure origin, handoff and source interfaces

This implements only the approved injected interfaces. Twenty synthetic tests
pass. It is not a real first-clock entry, a live file adapter, a production engine
integration or a real evidence checker. Every snapshot reports verification and
profile qualification as false.

The injected entry captures one clock origin before setup. One `BootstrapOwner`
keeps that origin, its output reservation, event ledger, original source slots
and immutable captured bytes. Its nonserializable one-time handoff gives the
engine continuation the **same object**, rather than resetting a start or opening
the originals again. Work ends at `t0+295`; closure uses the same `t0+300` cutoff.
The real entry must start its timer before importing this component and still
requires separate implementation and review.

Owner slots exist before fake open dispatch. A source-bound port records the
Python-visible owned return before identity work or deliberate record allocation.
Known no-handle failure, typed null and unreturned operations do not become
guessed handles. Read observations record defined byte counts before copy/hash
work; known bytes, acknowledged hash updates and unknown hash/read tails remain
separate. Central bootstrap error cleanup uses the original closer once. This is
application ordering, not an atomic native/ctypes or no-leak guarantee.

The source-loader interface requires the current owner's immutable captured bytes
and live leases. It permits only the fixed own-module/dependency map and explicit
prototype stdlib names, resolves relative imports through that map, and rejects
unknown paths, cycles and preloaded own helpers. The injected compiler receives
the original captured bytes. Its late/unknown returns cannot be retried into
success. No real source loader, normal import fallback or filesystem compiler
adapter is provided.

Fakes use exact three-field source pins and synthetic Python byte documents.
They exercise allocation/query/read/digest failures, delays, uncertain/late
closes, foreign contexts, stale roster changes, output ownership, duplicate
handoff, source/event admission and stub pass flags. They compile synthetic
syntax only; no old helper or payload is imported, hashed or executed. Test
imports happen before the injected origin, so these tests cannot claim the real
entry's clock boundary is qualified.

The prototype admits at most16 declared sources, further narrowed by
`10*N+8<=128` to at most12. These are smaller source-interface bounds; they do
not expand or establish fit for the future256-original/2,048-event roster.
The earlier accepted orchestration source remains unchanged.

Real metadata and sink API bindings, exact role/authority/call budgets,
production engine continuation, captured-byte evidence checkers and all live
qualification remain pending. The separate Unicode fixture is not a pack/wire
or runtime authority. The old failed experiment and incomplete external timeout
remain unchanged. The author does not self-approve this successor.
