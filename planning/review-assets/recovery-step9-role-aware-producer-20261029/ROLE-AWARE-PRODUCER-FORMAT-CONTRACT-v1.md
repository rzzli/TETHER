# Complete role-aware ledger schema (design only)

The machine contract defines the complete binary tables and validation law for a prospective role-aware producer. It answers the ten pre-code question groups; it does not implement a codec or authorize a producer, native call or original-file inspection.

Canonical first facts live in preallocated source-owned Python slots. An ordinary direct reference assignment retains the original scalar/count/error/clock object before packing, flags, cache updates or diagnostics. Presence derives from sentinel identity, so observed zero and NULL survive later failure. Encoded 256-byte call records are derived immutable snapshots. The real native-to-Python conversion window remains unqualified.

The contract freezes a 4,096-byte header, eight 64-byte section descriptors, 256-byte file/call rows, 64-byte module rows and 1,024-byte diagnostics. It closes API IDs, exact typed atoms and observedness, integer versus IEEE754 clock bits, flags, offsets, no-gap section lengths, hashes, path/query ownership, role/capture states and conditional artifact membership. All fourteen API atom types are supported, while complete ledgers permit only the seven original-file APIs; the other APIs require an explicitly unqualified fragment envelope.

Diagnostic slots are borrowed two at a time and recycled only when uncommitted after the final throwing post-check. Actual original/formatter errors commit permanently by identity. Protected cleanup capacity is explicit; 16,384 successful calls do not consume 32,768 diagnostic slots.

Generated checkers receive actual same-owner immutable artifact bytes. A decoded ledger or ordinal cannot mint a live owner, token, source observation or byte capability. Legacy projection is a producer-only adapter accepting a genuine same-owner ProducerSnapshot; it preserves actual opaque diagnostic tokens and source facts. Pure codec round trips cannot establish the unchanged 48-history integration or live provenance.

In addition to the previous conservative 113,985,546-byte named storage allowance, the schema separately budgets LIVE Python slot-reference and bounded primitive/string payload terms: 13823488 bytes. The combined named bound is 127809034 bytes. Object/container headers, allocator, original exception graphs, module objects and actual RSS remain unknown. The 256 MiB ceiling belongs to the vocabulary-only/new84 harness; it is not an inference RAM/VRAM/KV claim.

The finite fixture plan separates independent literal format tests from future genuine-producer raw-first, diagnostic-reuse, byte-issuance and legacy integration tests. Exact future roster/consumer graph, real first-entry/FFI, physical output/readback reservation, resource fit and new84 runtime remain open. No production encoder source exists in this stage.
