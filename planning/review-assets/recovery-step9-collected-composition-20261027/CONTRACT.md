# Real-input recorded four-arm integration

27 October 2026. Authorized engineering continuation of R09 under the existing
sixteen-step plan. The previous frontier was too broad: human references gate
scientific qualification, but the four-arm runner still accepts only an invented
request hash. Connecting verified collected inputs is necessary engineering.

## Scope and interface

Extend the existing composition, rather than creating another controller:

```python
CollectedSourceInput(authority_path, authority_sha256, roots, category)
smoke(output, tokenizer_authority, tokenizer_roots, *, collected_source=None)
verify(path, sha256, *, deadline=None, source_roots=None)
```

Absent collected input preserves the invented behavior. A concrete immutable
caller object supplies the source authority and approved root capabilities.
Serialized names never select executable classes. The real path is generic over
receipt-verified eligible same-category contemporary T6 inputs supported by the
existing recipe; it does not hard-code IL6R or a new expected request hash.

Rebuild the source parent and chosen existing literal-case-overlap retrieval
inside the single case timer. Qualify every candidate, including exclusions.
Use logical `case_run/source` parent references so moving the run does not read
its original output directory. Source-inclusive replay receives approved original
input roots explicitly; archived locator metadata cannot authorize filesystem
access. This claims run-bundle relocation, not autonomous restoration of all inputs.

Hold ordinary read-sharing locks on the authority and all pinned source inputs
through dispatch and final source verification. Cache hits require unchanged
parent/cell/quote inventories and the active source lease. Refuse protected paths,
evaluator-only/future ancestors, wrong roots/category, nonempty features or
modified inputs using existing admission/reconstruction rules. Record the effective
authority, roots as locator-only provenance, source parent, full retrieval proof,
coverage, current code and all quote/cell outputs.

## Honest recorded outputs

Keep one AsOf stage, five adapted Virtual Biotech stages and two pure baselines.
Recorded real-data stimuli copy complete original `/statement` strings only;
they are evaluator fixtures, not model-generated scientific interpretations or
reference answers. Limit claims to the inherited active cap and unique verbatim
statements within the existing 1,800-character validator limit. If no such whole
statement fits, use explicit fixture abstention; no text clipping or repair.
Unknown scientific context, parent availability/missingness and raw fields stay
unchanged. All numerical features remain empty and probabilities null.

Pure excerpt count is explicitly `min(3, inherited max_claims)`, satisfying the
source request's bound without changing it. Existing invented requests retain3.
Lexical query remains the full verified question. Preserve distinct grounded and
scientific-record hashes and recompute policies, selections and reviewer views.
Remove invented-only scope labels from collected outputs. No masking/blinding or
policy-quality superiority is claimed.
