## Interpretation boundaries

The completed comparisons can support a finite conformance finding and a replay-verification correction. They do not establish clinical/scientific truth, natural error prevalence, calibrated target probabilities, unseen generalization, all-input semantic equivalence, or superiority over the independent validator. Actual operational invariants such as output reservation, immutable state, transport bounds, timeout handling and recovery rely on separately retained runtime witnesses; self-consistent archived declarations do not prove physical execution or power-loss durability.

The shared Windows host, fresh-process imports and tracing instrumentation affect the cost figures. Logical input bytes are not physical I/O. Cross-version native archives differ, so their comparisons establish matched semantic-policy outcomes rather than a controlled identical-byte speed comparison. No live provider call, new dataset acquisition or new human-review gate was introduced.

## Audit procedure and retained initial limitation

[extract_evidence.py](extract_evidence.py) parses retained records, checks committed anchors/current pins, counts the declared grid, checks independent import/runtime boundaries and indexes pre-existing qualifications. It invokes no product, analyzer or reconstruction code. Its first invocation stopped before writing evidence because Windows' default text decoding could not read the Unicode coverage map; setting the read explicitly to UTF-8 resolved the evidence-tool issue. The successful invocation produced the retained index above. This tool is not an additional product test suite or independent numerical reanalysis.
