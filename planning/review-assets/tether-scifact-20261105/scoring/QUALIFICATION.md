## Interfaces

- `native_contract.validate_prediction(value, corpus, expected_claim_id=...)` returns a recursively frozen copied native `{id, evidence}` prediction. `corpus` maps integer or canonical string document IDs to records containing ordered `abstract` sentences. Simultaneous integer/string aliases for a used ID are rejected. SUPPORT/CONTRADICT labels and ordered unique in-range sentence IDs are required; empty rationale lists and empty evidence are valid native predictions. Semantic correctness is not checked.
- `native_contract.parse_prediction(payload, corpus, expected_claim_id=...)` adds strict duplicate-key/nonfinite JSON parsing and a 1 MiB byte limit.
- `native_contract.validate_references(references, corpus, schedule)` is evaluator-only. It preserves optional claim/citation metadata, including repeated citation IDs, and rejects unsupported rationale overlap, empty rationale sets, conflicting labels and invalid bounds.
- `evaluate.official_metrics(golds, predictions, evaluator_path=...)` verifies and executes only exact pinned scorer bytes and returns all twelve native metrics. It checks native shapes and schedule ordering; source sentence bounds require the corpus-aware codec. The current exact source path is `data/reference/scifact-evaluator-66feffc5/evaluator/eval.py`.
- `evaluate.evaluate_schedule(schedule, corpus, golds, records, evaluator_path=...)` preserves every scheduled ID and scores identical raw/checked candidates. Records have `id`, `producer_status`, `check_status`, `prediction` and optional `reason`. Failed/unexecuted production requires `prediction: null` and `check_status: not_run`. Native score files use a disclosed failure-as-empty projection; the operational ledger never treats those placeholders as successful NEI answers.

Supplemental strict case correctness requires the exact evidence-document set, correct document labels and a complete allowed rationale within the official abstract cap `max(3, shortest gold rationale length)`. This is distinct from official micro F1. The result records correct-and-admitted/all-scheduled, correct-but-rejected, native NEI, errors and missing execution separately. It supplies no calibrated probability or unrestricted scientific-truth judgment.
