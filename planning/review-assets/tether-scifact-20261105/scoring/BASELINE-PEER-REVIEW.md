# Bounded SciFact baseline peer review

The reviewed baseline's train-only pair vocabulary, separate whole-unlabeled-corpus retrieval index, fixed SGD settings, label ordering, sentence selection, native NEI representation and deterministic tie ordering align with the declared modest baseline. A direct fictional check compared the stored numeric inference formula with the actual fitted scikit-learn estimators: all 12 document probabilities and six rationale probabilities agree within `1e-14`. This is numerical conformance, not scientific generalization or calibrated probability evidence.

One concrete loader defect was reproduced: the array payload was hashed, but ZIP inspection and NumPy decoding reopened the pathname. Replacing that file immediately before `np.load` made the loader accept coefficients different from the checked bytes. [Original peer probe](baseline-peer-attempt01/REVIEW.json) retains that failure and the exact reviewed source copy.

The correction reads each model file through a bounded capture and uses the verified array bytes through `BytesIO` for both ZIP inspection and numeric decoding. Exact array member names are checked, and CSR dimensions, integer indices/pointers, monotonic offsets, exact nonzero counts and column bounds are validated before matrix construction. These checks also prevent the tested silent fractional-index conversion, truncated data and out-of-range column acceptance. [Failing regressions](baseline-loader-red01.log) retain four failed assertions and one schema error; [corrected regressions](baseline-loader-green01.log) pass all 12 test methods. The [unchanged second peer probe](baseline-peer-attempt02/REVIEW.json) still matches the scikit-learn probabilities and now preserves verified coefficients despite replacement of the disk path.

The final reviewed baseline source SHA-256 is `4af7440bc32e643c272c12f10bd272d67fb0530ace27cad3ed448373a0005fa8`. The actual preparation output's fit-pair fields are `claim_id`, `doc_id`, `label`, `negative_basis`, `rationale_sentences`, and `rationale_sets`, matching the learner's consumption; an earlier interface message with different field names was superseded and did not require a code change.

The loader remains for trusted, externally pinned model artifacts. This review does not establish malicious-code isolation, a general untrusted-NPZ security boundary, process memory enforcement or model-training provenance. Those obligations belong to the native preparation/policy/worker gates. No actual SciFact reference, development prediction, fitted production model or model-provider call was used in this review. The initial and corrected probes each use an authored fictional learning problem; the protocol's real fit/tune/evaluation remains pending.
