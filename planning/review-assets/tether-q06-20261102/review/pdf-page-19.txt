S7. Verification, failures and resource interpretation
Preparation audits retain 789 registry checks, 1,238 input checks, 1,163 reference checks and a separate

evidence, not additive independent validation samples. Final runner, auditor and analysis preparation suites
contain 36, 25 and 17 methods respectively. A keyed-dictionary/list mismatch in the independent auditor was
reproduced in a retained regression and fixed before the actual study. No actual native study was run under

Production has one original-row enumeration, 203.828 seconds wall and 198.984375 seconds CPU. Sampled
RSS is 241,364,992 bytes and checkpoint-observed lifetime process peak is 305,827,840 bytes. Source
verification is an overlapping 197.812-second subphase. Separate audit has one enumeration, 7.125 seconds
wall, 7.046875 seconds CPU, sampled RSS 327,589,888 bytes and peak 333,893,632 bytes. Combined
completed logical hash reads are 143,349,572,350 bytes. No physical I/O or dollar-valued platform cost is
inferred from this.
The unchanged resource table gives 197.812/203.828 = 97.0485% for the source-verification share of
production wall time. Production completed 140,452,303,784 logical hash bytes, equivalent to 49.0021 times
the 2,866,248,239-byte source frame; audit completed 2,897,268,566 logical hash bytes. The ratio is a
logical-work normalization, not 49 measured physical disk reads. Cache behavior, physical I/O, failed partial
reads and platform costs remain unmeasured. Production time is dominated by verification and must not be
described as model-only or agent-only inference cost. These descriptive ratios are derived from the retained
measurements and do not modify their values.
