Structured deterministic grading and process-level evaluation are represented by TxBench-PP [8] and
BiomniBench [9]. TETHER does not establish priority for any of these individual ideas.
Our narrower question is whether a local implementation can preserve a declared source-reporting contract
through source selection, normalization, generation, reference construction, scoring and retained execution
records. The implemented contract treats source availability, hypothesis scope, evaluator ancestry and exact
field bindings as first-class constraints. We evaluate native-field copying and deliberately designed failures; we
do not evaluate target ranking, experiment design, mechanism inference or therapeutic recommendations.
The contribution is an inspectable combination of versioned evidence admission, immutable source-bound
records, explicit missingness, separate generation and evaluation roles, durable execution accounting and
source-inclusive replay. Its empirical support is a small technical feasibility study and a negative
model-development result. The perfect literal baseline is an expected ceiling for a copying task. It is evidence
that this reporting path works on the selected inputs, not evidence of biomedical reasoning or a general
advantage over other agents.
2. Implementation and threat model
The frozen study implementation and its later software releases are distinct objects. Sections 3-4 report the
unchanged experiment and its separate source auditor. TETHER 0.4.1, 0.4.2 and 0.5.0 were qualified after
that study; their additional checks and execution limits are described explicitly below and in Supplement S10.
No later software test upgrades an earlier run's guarantee.
2.1 Evidence, time and hypothesis scope
TETHER separates cases, source snapshots, evidence packets, input-lineage nodes and execution artifacts.
The default Python runtime has no third-party dependencies; actual-format Parquet ingestion uses the optional
pinned PyArrow 21.0.0 dependency. Version-two evidence is copied and recursively frozen on admission.
Ledger commitments are checked against admitted canonical fingerprints. Features bind to a hypothesis
fingerprint covering canonical target and indication identifiers, namespace versions, intended action, modality
and tissue. Raw observations can remain contextual when a numerical feature is inapplicable.
Information availability is separate from computation time. A result newly computed from eligible older inputs
can qualify; an ancestor containing later information or an evaluation-only artifact cannot. Mapping and
annotation parents belong in the same eligibility graph. Public download dates provide present-day upper
bounds on observed availability, not proof of historical first availability. Null dates or unresolved source context
are not silently supplied from a newer release. The present experiment uses a contemporary cutoff and does
not establish a historically uncontaminated clinical forecast.
The implementation checks declared identifiers, roles, dates, hashes and source contents under trusted local
configuration. It does not authenticate a provider's original assertion, defend against a hostile administrator,
prove correctness of supplied metadata or provide an operating-system security sandbox. A signed provider
provenance chain is outside the study. Temporal checks are only as informative as the retained source
metadata.
