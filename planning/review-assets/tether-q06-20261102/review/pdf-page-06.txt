runtime and extra code pins, sources, receipts, task and reference seals, denominator register, fictional
qualification, schedule, budgets and analyzer. Limits include 3,600 seconds for execution and a separate 3,600
seconds for audit, 2 GiB checkpoint process memory and 256 MiB study output. Logical completed hash reads,
row enumerations, CPU, wall time and memory checkpoints are retained. Repeated hash reads are logical
work, not measured physical disk traffic. No new model call, network transfer or provider charge occurs in this
experiment.
