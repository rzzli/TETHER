# Reported module path dataflow before the platform revision

This source-only review covers child v8 (`28a515c2e7d8301f7648152014e481c9a98de1559ea76d3d23ca533e1cfb8a18`) under prospective root policy `7e59903195890e06c01a3c1e409ae17b0c71fd38374c291cdf690702e298d50e`. No reported image file or native API was inspected or invoked.

Old `Runtime::modules()` obtains every image through `module_path()`, which calls `GetModuleFileNameW` and then `absolute()`. The latter calls `GetFullPathNameW`, `GetDriveTypeW` and filesystem lexical normalization. Its `same()` also applies Unicode `towlower` and lexical normalization. Those operations do not constitute authentication of loaded bytes, and they do not implement the selected strict, data-only ASCII/slash rule. Reusing them for platform reports would hide rejected path spelling and make a zero reported-path-filesystem-operations claim inaccurate.

The new module guard must instead copy each complete raw `GetModuleFileNameW` return and snapshot name, then validate/compare them using only bounded UTF16 data operations and the shared policy contract. Reject ambiguous spelling rather than resolving it. Do not pass platform-report strings to `absolute`, `module_path`, `no_reparse`, `Lease`, `filesystem::canonical`, file attributes, hashing or a loader. Fixed self/runtime contexts are independently supplied and validated; when a runtime report matches one of those exact contexts, any identity check uses the predeclared known pin path, not a new path discovered from that report.

Existing loader work on approved core/self paths remains separately explicit: leases, hashes, full-path module loading, native-module identity checks and process pinning still occur there. Existing parent startup-candidate leases also remain predetermined inputs. Therefore the intended narrow claim is **zero filesystem operations derived from reported platform-image paths**, not zero filesystem operations for the entire native step. The16-name historical census classifier and its frozen results remain unchanged; no additional census is planned.
