A JSON `\u` surrogate-half cut is an incomplete ASCII escape, not an incomplete UTF-8 scalar.

**Recommended next work is a separately versioned coverage experiment, with two distinct evidence levels.** First prepare a model-independent byte/chunk suite against an independent UTF-8 state oracle: every interior split of representative valid 2/3/4-byte scalars, completion across chunks, complete-scalar-plus-pending-tail chunks, invalid continuations/overlong/surrogate/out-of-range bytes, and premature EOF. This gives guaranteed coverage of deliberately constructed byte boundaries with no model search. A pure Python suite tests its own implementation; a later reviewed exact-vendor-source harness could additionally exercise the retained decoder/grammar internals. Neither establishes actual pinned-DLL token filtering or vocabulary EOG behavior.
