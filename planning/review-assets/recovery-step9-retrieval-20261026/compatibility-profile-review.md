`data/reference/recovery-r09-preparation-verifier-034-20261026/`. All 297 prior
source/resource pins matched before this slice, as retained in BEFORE-VERSION.json.

Working 0.3.5 adds separate bounded retrieval composition. The declared legacy
semantic helper delta is the initializer version only; no older fixture gate,
admission kernel, execution policy or response contract is weakened. The profile
records its predecessor hash and current initializer hash. New current-package
parents are required for the new bridge; an old source receipt does not silently
acquire current-package authority.

Acceptance requires full validation, seven installed legacy families and matching
reviewed frozen 0.3.1/0.3.2/0.3.3/0.3.4 replay. Archived code is never executed
automatically. General native relocation and scientific validation are not implied.
