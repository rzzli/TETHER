## Minimal legitimate composition

The real path can qualify an explicit candidate universe by passing all its IDs through current source preparation, independently replaying every original row, then recovering original GroundedObservations through a small trusted binding helper. The public source-preparation result currently returns a request/receipt summary rather than a live store; the implementation must describe how it obtains originals without accepting arbitrary decoded caller records. Rebuild them from the verified preparation/source authority under the same locks, or internally return them from that trusted qualification operation without serializing a bypass into public manifests.

The synthetic path can use a narrow immutable record map authenticated against one new pinned source-only corpus resource, with a small synthetic compiler. It does not need a fake contemporary EvidenceStore. Both paths can produce the same structurally validated question request while retaining distinct authority kinds. Structural question validation alone does not confer either authority. Shared rank/serialization and source-copy helpers are reasonable; a new general controller, role hierarchy, source database or runtime policy is unnecessary.

The writer/verifier should retain exact universe/source anchors, policy, ranking inputs, exclusions, original selected records, compiled request, pointer table and four-arm access metadata. Replay requalifies the declared universe and recomputes selection/compilation with bounded exact-byte reads and required-resource path binding. No cached result or output-local metadata becomes an independent anchor. Current preparation payloads can establish source-complete rendering, but do not claim that a measured hypothetical history covers every future history or overrides StudySession's existing byte quotation policy.

## Finite acceptance emphasis

- A changed excluded candidate must fail before ranking even if the selected records would be unchanged.
- Forged synthetic profile, authority kind, original-record hash, external anchor or source citation must fail. A DEMO corpus cannot invoke the contemporary compiler through profile replacement.
- Reverse input order without changing stable-ID tie semantics; independently test literal-case ranking, count caps, oversized-first skip/continuation and zero overlap.
- Replay must detect selected ID/order/policy/query/coverage/alias tampering after internally consistent resealing. All-original-field preservation is checked against qualified originals.
- Empty declaration, all-over-cap, raw-QC failure and unknown collection coverage stay distinguishable. No failed candidate is replaced; no scientific answer or absence claim is fabricated.
- The second recorded cell must fail before dispatch when the shared time/input/output ceiling is exhausted. Failure, interruption and output contention retain accounting and never repeat a potentially dispatched call.
- Existing installed legacy/fixed-fixture verification still passes; new offline replay cannot launch a process, read evaluator answers or invoke mutable tools modules.

These are implementation criteria, not a new approval request or a demand for human scientific references before engineering.
