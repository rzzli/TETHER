`make_profile(SourceBytes, *, check)` hashes the six exact captured new metadata documents, validates the frozen source roster and returns a factory-issued immutable `ValidatedProfile`. Matching captured bytes does not authenticate original files or prove their availability. `encode(profile, *, check)` returns complete pack bytes in memory. `decode(raw, profile, *, check)` independently validates every header and record against that profile and returns immutable metadata. Each call requires a caller check callback; its deadline/interruption exceptions propagate. No clock is started or reset.

The pack has an exact 188-byte header, two grammar records, four stages and 84 cases. All IDs, five header digests, raw document/grammar hashes, six authored ternary expectations, eligibility/harness kinds and token caps are source-bound. Lengths are checked before slicing/copying, including the 20 MiB total bound. Complete consumption is mandatory. Source hashing and parsing, bounded field/hash steps and output copying call `check`; this provides cooperative checks, not whole-process preemption.

The module has no filesystem, path-opening, import-loader, SDK or native interfaces. Tests use frozen 25 literal fragments and independent field inspection, plus one complete new-source roundtrip in memory and bounded malformed mutations. They never write the complete pack. Pack records contain authored expectations, not measured tokens, geometry, selectors or native observations. Nothing in this component grants runtime, profile, resource, scientific or original-source qualification.
