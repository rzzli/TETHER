# Pure supplied-piece coverage analysis

The implementation is paused at source `537a780a3d2d3b95d5fe4976cd8a073cf528db908badf3edf3e861e729ff8f9d`. It implements the [frozen API](UNICODE-PIECE-ANALYZER-CONTRACT-v1.json), not a tokenizer, native parser or profile-success gate. The fifteen [literal scenarios](UNICODE-PIECE-ANALYZER-VECTORS-v1.json) were frozen before implementation.

`analyze(cases, ledgers, vocabulary_size, eog_ids)` validates supplied data and derives coverage only from the three source-declared eligibility flags. It validates the complete raw document with the separately accepted strict byte oracle, reconstructs scalar intervals and verifies exact piece concatenation. Pieces are never repaired, normalized or decoded separately. Empty pieces retain their original token ordinal. A mixed witness must be a whole scalar inside the current piece; completing one begun earlier cannot supply that witness.

All valid piece intervals and class/matrix counts are retained. Each distinct complete width contributes at most once to a matrix cell at a boundary. The complete corpus determines lexicographic first boundaries and class-priority de-duplication. Unknown population cases suppress global totals and selectors while preserving known lower bounds. Declared harness exclusions have null measurements and a known zero population contribution; they are not measured absence. Unknown excluded cases still fail all-case QC completeness. Every returned nested container is immutable through ordinary access; `to_dict()` creates fresh mutable serialization containers.

The [author proof](UNICODE-PIECE-ANALYZER-PURE-PROOF-v1.json), `34c7886a...`, passes eight methods, all fifteen independent scenarios and 84 full frozen documents using explicitly synthetic one-byte pieces. That last construction deliberately has zero mixed coverage and establishes no tokenizer behavior. The independent [peer proof](UNICODE-PIECE-ANALYZER-INDEPENDENT-PEER-v1.json), `e3a45f48...`, passes eight own methods, 272 partitions of four authored scalar documents and all twelve complete-width/pending-width matrix cells. It also probes first selection, empty pieces, unknowns, exclusions and nested mutation.

Both proofs are component evidence. `coverage_complete`, `all_case_QC_complete` and `required_available` are analysis results; none qualifies native membership, source authenticity or scientific validity. The pure output may contain all boundary objects, while a future native row will need compact counters and complete arrays within its independently measured wire limits. No native row-fit, real-entry clock, general streaming resource guarantee or hostile-Python isolation is established.

The original failed recognition experiment and its incomplete external verification remain unchanged. Exact native wire/parser/pack/parent, real verifier/platform/checker binding, runtime decisions, full-vocabulary masking and integrated resources remain later gates.
