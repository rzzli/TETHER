Q03 must not become another generic audit layer. Start with a short source-only task specification: what question combines or scopes more than one record, which facts make an answer valid, and which unknowns force abstention. Then verify representative original rows and count usable source groups. Existing reference/candidate outputs and human responses cannot be used to create a fresh answer set. Previous cases and source frames retain their exposure limits.

For a genetics task, identity must cover study, locus, variant, build and allele orientation, with cohort/ancestry/sample size and overlap where required. The absent study table and unresolved composite join remain actual gaps; a locus match cannot fill them. Basic ABF colocalization, SuSiE and single-instrument MR have different inputs. A catalog correction does not validate any of them. For a clinical task, origin eligibility, ascertainment and source-supported outcomes remain necessary; registry completion is not efficacy.

If the current data support only an objective reporting/verification question, preserve that scope and evaluate a discriminating property such as valid-input rejection versus incompatible-source rejection under equal inputs/budgets. Do not relabel literal assembly as reasoning, pad answer fields to make thresholds differ, or manufacture independence. If a necessary source is missing, document the exact release/fields/access/size and the blocked artifact; do not start a new download worker or reopen a closed experiment automatically.

Q06 can still produce an accurate narrow technical working paper without causal/clinical claims if Q03–Q05 are unjustified. Submission readiness remains contingent on the already deferred owner facts and acceptance. This is a feasibility branch in the accepted plan, not completion by omission.
