## Scientific contract

Success of an implementation/measurement is separate from improvement in answer
quality. A weak or negative, correctly executed experiment completes its declared
measurement. It does not justify dropping cases, changing thresholds on evaluation
answers, replacing the selected method with a weaker easier-to-run implementation,
or claiming scientific improvement from provenance alone.

For SciFact, the current public development set is exposed. Its existing source-
component split has380 fit,82 tune and69 reserved calibration claims. Those roles
remain explicit. New training/configuration selection uses authorized training/
tuning inputs; dev labels remain evaluator-only during prediction. A pretrained
external solver introduces different supervision from the old linear baseline:
report this as a solver-condition comparison, not an isolated architecture effect.
An exact matched-supervision experiment may be added prospectively where feasible.

The strict supplemental SciFact criterion requires the exact document set,
correct document labels and a complete allowed rationale within the native prefix
cap. Extra rationale sentences alone do not imply strict failure. Official native
metrics remain separately reported. Error flags may overlap; any first-failure
partition must state its precedence and must not imply a causal decomposition.

Reference-derived rationale-only and decisive-evidence-removal masks belong only
to separately labelled diagnostic conditions; neither the masks nor their source
hints enter the primary solver's input. They measure response to interventions,
not ordinary retrieval performance. The prospective selective-answering route
uses the retained69 source-disjoint SciFact calibration claims if their eligibility
and non-use still verify. LitQA2's199 evaluated answers cannot fit a threshold
reported as calibrated on those same199. Until a separate eligible LitQA2
calibration source is qualified, its uncertainty/coverage curves are descriptive
or use predeclared fixed settings, without a calibrated-risk claim.

For all native tasks, preserve raw/checked pairing, exact candidate identities,
unknown/missing inputs and complete scheduled denominators. Reference papers,
gold rationales and supplied-source conditions have distinct roles. Gold-source
diagnostics are never merged into ordinary retrieval performance. A repeated public
development evaluation is not an untouched holdout or new independent study.

ALCE, ScholarQABench and R2E answer different questions. This programme measures
scientific answer production, citation support, synthesis and ranking; it does
not validate therapeutic efficacy, calibrated clinical probabilities or causal
genetics. Model judges need qualification against released annotations/controls;
self-reported confidence and a second agent's opinion do not establish truth.

## Execution, acquisition and preservation

The new authorization permits needed public data/checkpoint/dependency acquisition
and local implementation, after explicit version, license, size and hardware
checks. Use isolated new paths and receipts; do not invoke or change the original
download worker or stopped monitor. Existing model assets can be reused after
their receipt checks. Keep paid-provider spending at$0 unless the owner separately
authorizes a concrete paid route. No external scientific expert input is required.

Keep all old frozen code, preparations, predictions, failures, scores and releases
unchanged. New code belongs in separate experiment modules; any reusable core fix
requires a regression and a versioned migration rather than retrospective changes
to old outputs. UTF-8 and LF must be explicit on Windows. Temporary files, caches
and new subprocess import prefixes stay inside the workspace.

Before each actual experiment, retain a protocol, input/code/environment pins,
model/configuration, schedule, budgets, failure accounting and independent scoring
plan. Qualify invented-data controls first. Reserve fresh output directories;
retain interruption/failure records and never automatically repeat an uncertain
inference call. Track executed calls separately from reservations, unqualified
usage and unexecuted cases. Record wall/CPU/memory, context/truncation, selected
bytes and local inference usage with their actual measurement boundaries.

Reuse source verification at justified boundaries rather than indiscriminately
rehashing whole environments per small case. Hashes establish observed byte
identity, not continuous host attestation. Native-library compatibility and GPU
support require actual probes. Software installations outside approved isolated
paths, credentials, inaccessible files or a material subjective decision are
escalated only when needed; routine fixes proceed autonomously.

The new experiments must be real task executions, not reference replay, an
all-abstention shortcut, a documentation-only substitute or an unscored smoke.
If a required asset is unavailable after reasonable attempts, retain the precise
blocker and keep the relevant task incomplete. Do not silently reduce the goal to
the stages that happen to be easy. Earlier conditional clinical/MR/T2–T5/H6,
full competitor reproduction and owner-deferred publication facts remain outside
this new semantic-capability sequence.
