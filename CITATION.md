# Citing TETHER

Use **TETHER: Target Evidence Tracking Harness for Evaluation and Reproducibility**, the exact source commit, and the engine/wrapper versions used for your result. Repository: [github.com/rzzli/TETHER](https://github.com/rzzli/TETHER). A Git commit is a code identifier, not a publication date or scientific validation.

Author order, affiliations, funding and competing-interest declarations remain owner-pending. No author list, DOI, publication venue or publication-ready citation is invented here.

When using evidence, cite its provider and the specific study/release retained in the run's provenance. [Open Targets Platform documentation](https://platform-docs.opentargets.org/) describes the source platform; TETHER does not own or independently validate its underlying scientific claims. The [catalog](data/catalog/README.md) distinguishes requirements from collected/validated data.

The [results guide](docs/RESULTS.md) labels aggregate arithmetic replay, source replay, software controls and scientific limitations separately. Cite the applicable result scope rather than treating all retained development runs as a single benchmark.
